# 安装与使用说明（SaltyGoose · 盐选七步法 1.0）

> 一套面向**知乎盐选短篇**的七阶段写作流水线：选题 → 梗概 → 细纲 → 写作 → 润色 → 初审与终审 → 交付。配 **9 个零依赖 Python 校验脚本**、一份口径唯一权威表（`references/shared/authority-table.md`，AT-01~81）、33 个题材卡文件（32 张卡 + README），以及一层跨文件一致性断言。

## 一、这是什么

一句话：**它把"写一篇能过稿的付费短篇"拆成七个可验收的工序。** 每个工序只解决一个问题、只产一个文件、只过一道门；前一道没过，后一道不启动。

| 层 | 内容 |
|---|---|
| 主文件 | `SKILL.md` —— 可执行入口：触发语 / 七阶段一览 / 四道确认门 / 产物链 / 全局铁律 |
| 多 agent | `AGENTS.md` —— 审稿隔离 sub-agent 边界 + 宿主预交付门禁 hook |
| 流程规则 | `references/` —— `README.md`（门总览+路由+加载索引）+ `shared/`（8 个横切口径）+ `stage1-topic`~`stage7-delivery`（每阶段四文件：workflow/quality-gate/self-check/rules），按阶段加载，禁全量同读 |
| 产物模板 | `templates/` —— 00-08 产物链模板 + 送机检提交包 + 确认门记录 |
| 长期资产 | `assets/` —— 32 张题材提示卡（genre-cards/）+ 范文库（exemplars/）+ 术语表 + 来源白名单 + 红线正本 + 执行提示词 |
| 配置与示例 | `config/default-config.md`（路径与偏好，无数值阈值）+ `examples/full-run/`（迷你全链样例） |
| 执行面 | `scripts/` 9 个校验脚本 + `tests/run-tests.py` 金标准回归 |
| 文档 | `docs/` —— 本文件 + CHANGELOG |

**核心口径**（数值唯一权威 = `references/shared/authority-table.md`）：

- 正文 **12000-16000 字**（AT-01）
- 单章 **1800-2800 字**（AT-02，情绪拉扯章可至 2800-3500，须注明）
- 全文 **6-8 章**（AT-50，附五档字数→章数查用表）
- 主付费墙字位 **3000-4000 字**，中卡点 45-55%（AT-04 / AT-10）

## 二、怎么用（按你的环境三选一）

1. **有支持 Skill 的 agent（如 ima / WorkBuddy）**：把整个目录作为技能注册或加载，直接说"帮我写个盐选故事"即可触发。技能会先问一轮输入收集（想法 / 素材 / 赛道 / 执行方式二选一），再进七阶段流水线。
2. **只想读方法**：把 `SKILL.md` + `references/` 当方法论文档读，照样能照着写——四道确认门与各阶段质量门就是 checklist。
3. **想跑脚本自检**（需本机 python3 ≥3.8，**无需安装任何依赖**）：

   ```bash
   # 技能本体自检（改过脚本或口径后必跑）
   python3 scripts/check-consistency.py    # 跨文件口径一致性 + 死链检查：文件级 + 跨文件同文 + AT 行级断言
   python3 tests/run-tests.py              # 金标准回归
   python3 scripts/check-all.py            # 一键门 = 探针 + 一致性 + 回归

   # 写作过程中用（对某一篇稿件；除 check-mss 外均为位置参数）
   python3 scripts/check-length.py 03-正文.md                       # 字数与章门
   python3 scripts/check-metrics.py 03-正文.md                      # 可测指标与注水启发式
   python3 scripts/check-ai.py 04-正文净稿.md                       # AI 味六合一速扫
   python3 scripts/check-mss.py --text 项目-书名/机检提交/正文纯文本.md --foreshadow 伏笔回收.csv   # MSS 机检结构分
   python3 scripts/check-artifacts.py 项目-书名/                     # 产物链字段对账
   python3 scripts/check-all.py 项目-书名/                           # 交付门：产物链 + 三件套 + 整篇核验
   ```

   全部脚本遵循同一套退出码语义：**0 = 全过 / 1 = 用法错误或输入无效（空稿 / 空正文 / 文件不存在 / 参数错误） / 2 = ⚠️ 待修 / 3 = ❌ 必修**。按阶段调用速查见 `scripts/README.md`。

## 三、环境要求、宿主参数与降级条款

| 项 | 口径 |
|---|---|
| Python | ≥3.8，只用标准库（re / sys / pathlib / py_compile / csv 等） |
| contextWindow | ≥32K（推荐 64K+）；单会话段只承载"本段输入产物 + 当前阶段规则" |
| maxTokens | 单次输出 ≥4K（推荐 8K）；单次输出封顶纪律：一条消息只产 1 个产物文件或 1 章正文 |
| 温度/采样 | 按宿主默认；本技能不设推理参数——质量靠质量门与自检兜底，不靠采样调参 |
| 硬件（显存/速度） | 技能层不可测；以"单次输出封顶"间接约束耗时 |
| 脚本不可用（环境问题 / 报错 / 文件损坏） | 按各脚本 docstring 的口径**人工执行同一标准**，结果标"⚠️ 人工核验（脚本降级）"；**降级不降门**——不改变阈值、不放宽"不过不前进" |
| 连续 2 个阶段靠降级通过 | 停下检查环境，禁带病硬跑 |
| 改过脚本 | 必跑 `tests/run-tests.py`；失败先修脚本再干活 |

> 会话拆分（长稿五段）权威口径见 `references/shared/session-split.md`；本表只覆盖宿主安装维度。口径冲突时**以宿主官方文档为准**。

## 四、分享边界

- **目录隔离**：技能文件夹只含技能文件与测试夹具。写作产物（00-08 产物链 / 投稿包 / 机检提交包）一律落盘到**技能目录之外**的项目目录 `项目-{书名}/`（默认建在用户工作区下），防止技能包与作品稿混杂、误随技能分发。
- **过程产物不入包**：投稿包只含两件（正文 + 后台投稿信息）；细纲 / 审稿报告 / 钩子表等留在项目目录备查。
- **外部对照源需自备**：`tests/external/` 的盲测对照源（同赛道真爆款 3-5 篇）涉及第三方版权，不随包分发——需要时用手头对标作品补充，缺位时盲测按降级规则标"⚠️ 无对照源"。
- **整包自含**：本技能为自包含技能包，分享时请整包（含 `references/` `scripts/` `tests/` `templates/` `assets/`）一并分发，勿拆散单文件引用。

## 五、效力边界（重要）

脚本只保证 **形式合规 / 结构合格**（L1 / L2），**不保证"出彩过稿"**（L3）——过稿仍取决于内容本身与真实读者反馈。

机检报告的结论只写"机检结构匹配"，禁写"保证过稿 / 必爆 / 确定能过"；语言风格、AI 味、代入感、人设记忆点等不评项见各阶段的"待人工复核清单"。

> **机检全绿 ≠ 能过稿。**

## 六、目录速览

```
saltygoose/
├── SKILL.md                  # 主文件：七阶段可执行入口
├── AGENTS.md                 # 多 agent 分工 + 宿主预交付门禁
├── config/                   # 默认配置（路径与偏好，无数值阈值）
├── docs/                     # install.md（本文件）+ CHANGELOG.md
├── examples/full-run/        # 迷你全链样例产物
├── references/               # 流程规则（按需加载，禁全量）
│   ├── README.md             #   门总览 + 门禁失败路由 + 加载索引
│   ├── shared/               #   8 个横切口径正本
│   └── stage1-topic/ … stage7-delivery/   # 每阶段四文件
├── templates/                # 00-08 产物模板 + 送机检提交包 + 确认门记录
├── assets/                   # 长期资产：题材卡 / 范文库 / 术语 / 来源白名单 / 红线 / 提示词
├── scripts/                  # 9 个校验脚本（零依赖）+ README 调用速查
└── tests/                    # run-tests.py 回归 + 金标准 + 夹具
```

> 写作产物不落在本目录内：七阶段产物链默认落盘技能目录之外的 `项目-{书名}/`（目录隔离纪律见 `SKILL.md` 第四节）。
