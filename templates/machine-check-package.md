# 机检提交/（送 check-mss.py 必产，与投稿包两件分立）

> 模板使用说明见 `./README.md`；调用口径见 `../references/stage6-review/workflow.md` 第二节。

```
项目-{书名}/机检提交/
├── 正文纯文本.md        # 04-正文净稿.md + 插回 [[首锁]]/[[二锁]] 标记，纯数字分节
├── 标题导语梗概.md      # 三字段显式列出
├── 金句列表.md          # 3-5 句 × ≤40 字（从正文金句位抽取）
└── 伏笔回收.csv         # 五字段（由细纲伏笔规划表导出，回收原句与正文逐字一致）
```

> **正文来源口径**：送机检的正文面派生自 **04-正文净稿.md**（stage5 R11 唯一正文来源）+ 插回双锁标记——**禁直引 `03-正文.md`**（03 是写作期稿，未过去 AI 味与净稿冻结流程；直引它 = 机检面与投稿面不是同一份文本）。标记位置与净稿逐字对应：`[[首锁]]` 锚定 AT-04 首锁字位（与 `--paywall` 锚句互校一致），`[[二锁]]` 落在首锁之后且产生新悬念（mss-rules 第一节第 7 项）。标记只存在于本包，禁入投稿正文。

> 送机检字数 = **AT-01 带 12000-16000 字**，无需折算；该带内付费墙绝对字位 3000-4000 与首锁占比 25-35% 天然共存，**不存在需要备案的例外稿**——若全稿确已越出 12000-16000，属篇幅不达标，回阶段 4 增删而非在机检包里打补丁（AT-01、AT-04）。
> 金句列表（3-5 句）≠ 投稿七字段"作品金句 1-2 句"——两口径各管各的交付面，不许互相顶替。
> 门禁自检：四件齐 ‖ 正文纯文本带 `[[首锁]]`/`[[二锁]]` 标记 ‖ 金句 3-5 句×≤40 字 ‖ 伏笔回收 CSV 五字段且回收原句与正文逐字一致。
