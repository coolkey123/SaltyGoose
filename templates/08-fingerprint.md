**六维指纹卡**（机检识别格式：每维一行 `- 维度: 值` 键值对；枚举取值权威定义见 `../references/shared/fingerprint.md`，枚举有更新以那里为准回改本表）：

- 叙事起点: （反常发现 / 身份困境 / 倒叙悬念 / 绝境求生 / 交易开局 / 觉醒复仇 / 悬疑惊悚 / 时空错位）
- 主角行动模式: （取证反击 / 隐忍蓄力 / 主动布局 / 逃离自救 / 以退为进 / 正面硬刚 / 旁观揭底）
- 核心反转类型: （身份/关系反转 / 动机反转 / 时空反转 / 认知框架反转 / 叙述者不可靠 / 无反转（报应兑现））
- 核心意象类别: （器物信物 / 场景空间 / 身体印记 / 文本记录 / 气味食物 / 自然天象）
- 关系翻转方向: （受害者→清算者 / 弱者→强者 / 被弃→被追悔 / 陌生→羁绊 / 局中人→揭局者 / 无翻转）
- 付费卡点触发情境: （认知颠覆时刻 / 身份揭穿瞬间 / 生死悬念顶点 / 情感决裂 / 真相反转将发未发）

**计划-实落双记录**：阶段 1 登记计划指纹（上面六行填计划值）；交付时回填实落结构（双峰实际字位/危机引擎实际轮换/钩位实落/实际章制，另起段落记录）；复盘更新台账。更新后跑 `check-fingerprint.py` 比对——任两篇 ≥2 维同值 = 同型预警（AT-48），连续 3 篇同模式触 AT-46 红线。

> 门禁自检：六维填全（机检 exit 1 = 未填全）‖ 实落已回填 ‖ 比对无同型预警。
