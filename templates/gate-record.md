# 确认门记录（gate-record，四道确认门通用）

> 模板使用说明见 `./README.md`；确认门总览与两种确认方式见 `../references/README.md`。
> 每道确认门过场时在项目目录留一行记录——门禁不是口头说过，是留痕。

| 字段 | 填写说明 |
|---|---|
| 门号 | 确认门①/②/③/④ |
| 门名称 | 选题定稿 / 梗概定稿 / 细纲定稿 / 成品交付 |
| 对应阶段 | stage1-topic / stage2-synopsis / stage3-outline / stage7-delivery |
| 确认方式 | 方式①（自动交付，用户可随时叫停回退）/ 方式②（用户点头后交付） |
| 门条件自检 | 该阶段 `quality-gate.md` 全部门 ✅；⚠️ 项附人工确认记录 |
| 机检状态 | 相关脚本 exit 0（或 ⚠️ 已人工确认） |
| 确认结果 | ✅ 通过 / ❌ 回退（回退到哪个阶段+原因） |
| 确认时间 | YYYY-MM-DD HH:mm |

> 记录示例：`确认门②（梗概定稿）｜方式②｜九字段齐+双版本齐+标题合规 ✅｜check-consistency exit 0｜✅ 通过｜2026-01-15 21:30`

> 门禁自检：门条件全过才记 ✅；❌ 必须带回退目标与原因，禁只写"没过"。
