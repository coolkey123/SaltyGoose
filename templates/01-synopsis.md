# 01-梗概.md（阶段 2，梗概卡九字段）

> 模板使用说明见 `./README.md`；本阶段流程见 `../references/stage2-synopsis/workflow.md`。

| # | 字段 | 要求 |
|---|---|---|
| 1 | 一句话梗概（双版本） | 20 字极简版（人物+事件+反转暗示）+ 100 字扩展版（身份+动作+爽点三要素齐）；公式：在【时空背景】下，一个【身份】的【主角】，因为【核心事件】，决定【核心行动】，最终【反转或代价】 |
| 2 | **目标读者与情绪承诺** | 写给谁（赛道/画像）、承诺什么情绪、**落地在哪**（由哪个字段承载兑现——通常指向字段 4 的主疼位）；禁空写"写给所有女性读者" |
| 3 | 核心冲突 | 谁 vs 谁、争什么、**为什么不能退让**；禁只写"两人矛盾"不写对抗轴 |
| 4 | 核心悬念三要素 | 利害关联 + 时空压迫 + 信息黑洞 |
| 5 | 情绪弧线任务清单 | 赛道弧线具体落法 + **主疼位指认行**（AT-73：被辜负/被误解/求而不得/身份落差/丧失五型指认 1 个主疼位，可叠加辅位但主疼位唯一）+ 三项量化：**靶点总数**（AT-33 密度 ≥15/万字、虐文 ≥18/万字，按 AT-01 篇幅带 12000-16000 字折算 = **总数 18-24 个、虐文 22-29 个**；填总数时须标出对应篇幅带，禁写无口径裸数字）/ 击穿级数量（虐文 ≥2 六星，其余 ≥1）/ 压迫递进四层（AT-81：按 AT-01 篇幅带四等分 → 单层 3000-4000 字，须强度递增非并列） |
| 6 | 双峰反转 + 分级 | 50-60% 放真相第一层、80-95% 放终局反转，各标 3 处可埋伏笔位；分级 A 级 ≥1 + B/C 级 2-4 个；反转铁律三条（回看 ≥3 暗示/不引入新信息/叙述者可以隐瞒不可以说谎） |
| 7 | 核心意象闭环 | 1 个信物/旧物：首现开篇 3000 字内、末现结尾 1000 字内、全文 ≥3 次且递进、闭环方式四选一（同义/对照/因果/翻面） |
| 8 | 主角弧光一句话 | 一句话答出"主角从 A 点（错误信念）到 B 点（新认知），转折点在哪" |
| 9 | 结局走向与暂定标题 | 结局走向（HE/BE/开放/双结局 + 一句结局画面）；暂定标题三档 三档（≤15 最佳/16-20 合格/>20 硬门未过）；不剧透；禁问号感叹号；核心词须在正文前 3000 字兑现（细纲标注兑现位） |

> ⚠️ **字段数为九而非八**（）：历史"八字段"口径遗漏了「目标读者与情绪承诺」与「核心冲突」两项——二者均有质量门条目在管（门 2 情绪承诺落点、门 5 单线对抗轴）却不在字段清单里，等于门管不到字段。AT-73 明文规定"主疼位指认**不另立第九字段**"，本扩编只针对上述两项，与该条不冲突。

> 门禁自检：九字段齐 ‖ 双版本齐 ‖ 反转铁律三条全过 ‖ 量化目标三项 ‖ 标题合规。
