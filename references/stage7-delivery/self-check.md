# 阶段 7 · 交付 — self-check（该怎么自己检查）

> **本文件回答：该怎么自己检查。** 该干什么/怎么做见同目录 `workflow.md`；验收线见 `quality-gate.md`；禁令见 `rules.md`。
> 脚本调用口径以 `../../scripts/README.md` 为唯一权威，本文件不复述。

## 一、交付前检查清单

| # | 检查项 | 跑什么 / 怎么核 |
|---|---|---|
| 1 | 正文字数实测 | `check-length.py`（投稿 docx 命名字数 = 实测值，差 >10% 即改名） |
| 2 | 投稿包两件在位 | 正文（docx/md）+ 后台七字段信息；过程产物已清出 |
| 3 | 正文无标记残留 | 投稿正文不含 `[[首锁]]`/`[[二锁]]`/任何方括号标注 |
| 4 | 付费墙分隔符在位 | `——以下为付费章节——` 在免费段与付费段之间；付费段起始句触发首次反转 |
| 5 | docx 命名 | 含标题 + 实测字数（《重生后我撕了婚书_12800字》形态） |
| 6 | 七字段逐项核 | 名字 ≤20 字无问号感叹号 / 类型 / 标签 3-5 / 主角名字 / 主角人设 / 金句 1-2 句×15-25 字 / 简介 100-150 字 |
| 7 | 章题情绪动词 | 相邻章合并后的章题带情绪动词，禁平铺名词 |
| 8 | 条件项状态 | 平台口径/相似度未核项有"⚠️ + 原因"备注，无留空 |
| 9 | 送机检提交包四件 | 正文纯文本/标题导语梗概/金句列表/伏笔回收 CSV，与投稿包分立 |
| 10 | 指纹台账查重与回填比对 | 本篇实落回填后跑 `check-fingerprint.py <目录\|指纹文件...>`（exit 0 无同型 / exit 2 预警已处置）；新篇选题时查台账；两篇 ≥2 维同值 = 同型预警（AT-48） |

## 二、复盘自检

1. 复盘三问是否逐问答齐（禁"无问题"一句带过——每篇都有最接近被拒的点）；
2. 问题类是否同步登记跨篇台账 `{workspace}/saltygoose-repair-log.md`；
3. 结构指纹是否追加进台账（六维格式见 `../shared/fingerprint.md`）；
4. 未闭环问题摘要与指纹是否写入持久记忆；
5. 同一类问题是否已达连续 3 篇——达到即改技能文件，禁下一篇继续人肉兜底。

## 三、常见自查失败的定向修法

| 自查不过项 | 定向修法 |
|---|---|
| 正文字数与申报差 >10% | 用 `check-length.py` 实测值重命名（标称即实测） |
| 投稿正文带方括号标注 | 拿 `04-正文净稿.md` 重出——净稿是投稿唯一正文来源 |
| 付费段首句是背景交代 | 重写起始句触发首次反转（回阶段 4/5 修正文，不在交付层挪符号） |
| 复盘写"无问题" | 重写——复盘三问禁空答，找不出三个点说明审稿没做完（回阶段 6） |
| 同型预警（两篇 ≥2 维同值） | 回阶段 1 换模式重出选题（AT-46/48） |
| 指纹回填后未跑机检比对 | 跑 `check-fingerprint.py`——shared/fingerprint.md 明定阶段 7/复盘为调用时点，不可用时报"⚠️ 人工核验（脚本降级）"并人工两两比对（降级不降门） |
| 平台当期规则检索不到 | 按缺省形态交付 + 备注"⚠️ 平台当期规则未核（无公开来源）"，禁把无来源规则当改稿依据 |
