# 底层原理（principles.md）

> 供盐选七步法全阶段使用（Reference Gate 阶段 1 前必读）。本文件回答"为什么有效"——写作取舍犹豫时（这段删不删？钩子够不够？卡点放哪？），回原理层找判断依据，而不是背规则。数值口径的最终裁决见 `authority-table.md`（AT-xx 唯一权威）。
> 溯源：信息不对称经济学/付费三机制/容器论等原理层，提炼自盐选方法论体系（1514 篇盐选语料实证校准）。

## 一、核心模型：信息不对称经济学

盐选故事的一切，归根结底是**信息不对称的制造与消解**。故事里有四层认知：

| 层 | 内容 |
|---|---|
| 事实层 | 客观发生了什么 |
| 叙述者层 | 叙述者选择告诉你什么（可能在骗你） |
| 角色层 | 故事中的角色各自知道什么 |
| 读者层 | 读者基于以上信息构建的理解 |

> **爆款操作 = 让四层之间产生最大程度的错位，然后在关键时刻对齐。对齐的瞬间 = 反转 = 多巴胺 = 赞同/收藏/付费。**

**三种信息差（至少同时用两种）**：

| 类型 | 机制 | 效果 |
|---|---|---|
| 读者 > 角色 | 读者知道而角色不知道 | 焦虑感（"你别开那个门啊！"） |
| 角色 > 读者 | 角色知道而读者不知道 | 好奇心（"他为什么要这么做？"） |
| 叙述者 > 读者 | 叙述者在骗你，但你不知道 | 颠覆感（"我靠，原来是这样！"） |

**核心操作**：让读者与角色共享错误的认知框架，在揭示时制造"细思极恐"。（联动审稿：逻辑验证八查第 2 查"信息差三层一致"——叙述者隐瞒=合法伏笔，叙述者说谎=违规；角色不该知道的不能知道。）

## 二、读者为什么付费（三个机制）

1. **蔡格尼克效应**——人对未完成事件的记忆远强于已完成。付费墙的本质不是"挡住内容"，而是**制造认知上的未闭合回路**。推论：付费墙前最重要的不是"好看"，而是制造**认知失调**——读者以为自己理解了某件事，突然发现理解是错的，但还没知道答案。
2. **沉没成本**——读完免费部分已建立情感投入，放弃意味着"白费了前面的时间"。推论：免费部分的首要任务不是展示"故事多精彩"，而是**让读者关心角色的命运**。关心 = 投入 = 沉没成本。
3. **社交货币**——"你一定要看这个"（信息优势）/"细思极恐"（品味标签）/"看完沉默了"（深度标签）。推论：好故事要有**一个可以被一句话传播的核心概念**；有好奇心的一句话比有感动的一句话传播效率高得多。

```
付费转化率 = 信息不完整感 × 情绪卷入度 × 时间压迫感
```

乘法口径：三者任一为零付费率为零；缺 1 个亦大幅折损（付费卡点失效时按此三变量归因）。

**各赛道付费逻辑**：虐文 = 情感宣泄 + 意难平；甜文 = 幸福感 + 期待感；悬疑 = 信息不完整 + 求知欲；爽文 = 憋屈释放 + 成就感；脑洞 = 好奇心 + 新奇感。

## 三、算法逻辑（推荐流生存法则）

指标权重：**完读率（最重要）> 互动率 > 停留时长 > 跳出率**。

| 指标 | 要求 | 技法 |
|---|---|---|
| 降低跳出率 | 前 2 行留住人 | 第一句就给冲突/反常 |
| 提高完读率 | 读者"不得不"看到最后 | 持续的信息差 + 层层剥开 |
| 提高互动率 | 读完后产生强烈情绪 | 终极反转放最后 + 余韵留白 |
| 提高停留时长 | 密实不冗余 | 1.2 万-1.6 万字的密实文本 |

**推荐流占 96.5%+（多源印证，当期规则待核）**：用户**没有预期**——不是来找故事看，是刷信息流被你拦住的。标题必须 0.5 秒内制造好奇心；第一句必须 3 秒内制造"不得不读"；**竞争对手不是其他故事，是短视频、热点新闻和朋友圈**。

## 四、叙事底层结构与"发现"深度

所有故事都是同一个故事：`稳态 → 打破 → 追寻 → 发现 → 新稳态`。爆款与平庸的区别在于**"发现"的深度**：

| 层级 | 描述 | 读者反应 |
|---|---|---|
| 浅 | 发现一个新事实 | "哦" |
| 中 | 发现之前的理解是错的 | "没想到" |
| 深 | 发现整个认知框架是错的 | "细思极恐" |
| 极深 | 发现自己（读者）也是被操纵的一部分 | "我靠……" |

**可操作推论**：写完问自己——读者读完后，对"阅读体验本身"有没有新的认识？
**悬念的俄罗斯套娃**：每个解答都是新谜题的开端。选题阶段判断至少 **3 层**可解开的悬念（第 1 层开篇、第 2 层中段、第 3 层付费点附近）。

## 五、情感的物理学：交流电

好故事的情感曲线像**交流电**：紧张 → 松弛 → 更紧张 → 更松弛 → 终极紧张 → 彻底释放。

- 纯催泪故事是**直流电**（情绪只有越来越悲一个方向）→ 推荐流表现极差。
- 每一次"松弛"都让下一次"紧张"更有力（弹簧必须先压缩）。
- 松弛段不是浪费字数，是为下一波蓄力（但松弛段也要有信息量，不能空转）。

**情绪锚点法**：爆款从不写情绪名称，只写一个可触摸的物。❌"我很绝望" → ✅"那只蜂蜜水还放在桌上，盖子没拧紧"。
- 锚点必须是可触摸的日常物（血、保温杯、围裙、凉掉的汤）；
- **一个情绪只配一个锚点**（配三个物体 = AI 味的堆砌）；
- 锚点至少复现 1 次（第二次出现时意义已变）——与"意象 ≥3 次递进"规则联动。

**情绪浓度公式**：

```
情绪爆发力 =（角色困境 × 社会议题）÷ 信息差
```

分母项最反直觉：**信息差是反转的燃料，却是情绪的阻力**——读者事前越不了解主角处境，揭示时冲击越大；但情绪浓度要求读者先知道处境，再看着他被推进更糟的境地。**解法**：信息差用在"主角不知道什么"（对内），信息透明用在"读者知道主角正在经历什么"（对外）。

**情绪对冲**：爽点之后立刻植入一个虐点，中间用一个嗅觉记忆（母亲厨房的酱油味、医院走廊的消毒水味）触发连接。对冲不是抵消，是让下一次摆动更有力。

## 六、一句话法则（选题阶段最高优先）

> **如果你不能用一句话说清楚"这个故事为什么值得看"，那它大概率不值得写。**

三要素缺一 → 概念不成立，重写，**不要指望用写作技巧拯救**：①**有悬念**（听完想知道结果）②**有反常**（违反日常认知）③**有画面**（能在脑中成像）。（联动：阶段 1 一句话验证三关、阶段 2 质量门"梗概 ≤50 字讲清 + 勾出然后呢"。）

## 七、容器论：故事是容器的形状

| 容器特征 | 对写作的要求 |
|---|---|
| 手机屏幕（竖屏、小字、拇指滑动） | 段落必须短，一屏能看到 2-3 个段落 |
| 碎片时间（地铁、睡前） | 每个段落都必须能独立"发生"某件事 |
| 付费墙（3000-4000 字处切断） | 前 4000 字必须完成"投入建设" |
| 推荐流（用户没有预期） | 前 2 行决定生死 |
| 评论区文化（读者爱讨论反转） | 故事要给读者"讨论空间" |

纯文学适配纸质书，网文适配追更 APP，盐选适配知乎信息流。**不要用写纯文学的方式写盐选，也不要用写网文的方式写盐选。**

## 八、七步法的架构原理：规则库与执行面分离

七步法把"写什么、写到什么程度"的决策（**规则库**：SKILL.md + references/）与"怎么量、量什么"的测量（**执行面**：scripts/ 九个机检脚本）彻底分离：

- **规则库是口径的家**——所有数字口径唯一权威在 `authority-table.md`（AT-xx），references 各阶段文件只引用不重述，改数值只改一处；
- **执行面是门的家**——质量门的机检面全部落在脚本上，`check-consistency.py` 用跨文件断言锁定"规则库不许自相矛盾"，`tests/run-tests.py` 用金标准样例对拍锁定"执行面不许失去判别力"；
- **四道确认门是人机分工的家**——确认门①（选题）/确认门②（梗概）/确认门③（细纲）/确认门④（交付）卡住"返工代价最大"的四个节点；**质量门**卡住"不过不前进"的每一阶段；确认门按执行方式运行（方式①全自动 / 方式②逐阶段确认），但**质量门、编造防线在两种方式下均不豁免**；
- **降级条款是韧性的家**——脚本不可用时人工执行同一口径（标注"⚠️ 人工核验（脚本降级）"），**降级不降门**：门的阈值与"不过不前进"约束不变。

**为什么这样分层**：单文件 prompt 技能改一处口径要全文搜、还常漏；分层后"改口径 = 改 AT 表一行 + 跑一遍一致性断言"，断链会被脚本当场抓住。

## 九、爆款公式（缺一即零）

```
爆款 = 一句话勾人的概念
     × 多层信息不对称
     × 短段落分镜节奏
     × 600 字一个钩子的密度
     × 交流电式情感曲线
     × 读者自以为聪明实则被操纵
     × 平台容器适配
```

任何一项为零，整体为零。六维审稿不达标时，按这七项逐项归因。
