# 风格约束细则（style-rules.md）

> 供七步法阶段 4（写作）与阶段 5（润色）使用。AT 编号以 authority-table.md 为准，产物名按 00-08 链；文中"1514 篇语料实测校准三档"即口径校准结论。
> 核心心法：**段落是读者的呼吸，句号是呼吸的阀门，语感是呼吸的质地。** 三层质检合一：宏观（段落结构）→ 中观（标点呼吸）→ 微观（字词语感）。读者要从第一个字滑到最后一个字，中间不停顿。

## 一、硬规速查（写之前先记住）

| 项 | 规则 |
|---|---|
| 视角 | 第一人称限知锁定，只写"我"感知边界内的人事（番外切男主视角是唯一例外）；跳出"他/她视角"的句数 = 0（AT-59，三称稿不适用） |
| 对话引号 | 必须用「」，句号问号感叹号写在「」内；禁双引号/英文引号 |
| 对话段 | 1 句发言 1 段，不拆分；引导语≤5 字可同段，>5 字冒号留前段、对话另起 |
| 叙述段 | 1-3 句、整段 ≤50 字理想（51-100 警示优化、>100 必修——1514 篇语料实测校准，与机检/拒稿门同口径）、单句≤25 字；"≤4 行"行数口径=字数三档的行数化（≤50≈1-2 行、51-100≈2-4 行、>100 必超 4 行——AT-63） |
| 独句段 | 占比≥30% 达标线（25-30% ⚠️ 待修、<25% ⚠️ 重点修——⚠️ 级计 exit 2，片段模式参考不计；AT-12）；金句必独立成段 |
| 禁止段 | 4 句以上的段落（对话除外）；以逗号结尾的段落 |
| 标点（节制使用，非平台禁令） | `……` `——` **可节制使用、不再正文禁用**（实测 97.8%/68.3% 盐选作品在用——非平台禁令）；叙述层避免扎堆，情绪峰值段与对话段可留；`—` `--` 不用 |
| 段落间隔 | Markdown 稿：段间 1 空行；导语与正文间 1 空行；章节间 2 空行（盐选风格标准口径；若投站内编辑器按其渲染要求，段间不加空行仅换行，全文统一一种） |
| 章节标题 | **禁文字章节标题**（"第一章 风雪夜归人"式不合盐选调性）；只用**纯数字分节**（1、2、3 独立成行，不带点/括号等任何符号）；编辑只看"序号+节末钩子"；可选在正文开头加类型标签（如【古言爽文】） |
| 快节奏加严档 | 反转密集/沙雕转刀等快节奏赛道：每段≤30 字、一句一段（在"≤3 句/≤50 字"底线之上加严，防手机阅读晕字） |
| 金句 | 15-25 字（容忍上限 ≤30，AT-34 备注），每 500-800 字≥1 处，独立成段 |
| 结尾 | 最后 300 字落具体意象，不落抽象道理 |

## 二、段落计数规则（先会数，再会切）

- 句号、问号、感叹号算一句；逗号、分号不增加句数。
- 对话整体算一句（一个人一次完整发言，不按内部标点计数）。
- 破折号/省略号停顿：解释说明型按 2 句计，语义转折型按 1 句计。

## 三、五类段落规则

**1. 对话段（优先级最高，任何情况下不拆对话）**
- 1 句单独成段；对话内超过 3 个句号时从写作端拆分发言（"我不知道。真的不知道。你别问了。我知道自己错了。" → 拆成两段发言）。
- 独立动作句单独成段，引导语+对话另起一段。

**2. 金句段**：1 句独立成段。金句标准——脱离上下文也能成立、可截图传播、含强烈情绪或认知反差、15-25 字。多金句连续：递进各成段、并列合一段、对比各成段。

**3. 叙述段**：1-3 句。单句>25 字就拆（找破折号/逗号做拆点，拆在语义独立处，朗读不需要连接词就对）。段落起始可用"但/可/不过"，避免"但是"单独起段；段落必须以句末标点收尾。

**4. 动作段**：1-3 句。连续快速动作用逗号连接合 1 句（"她站起来，走到门口，推开门。"）；有停顿感的动作用句号断开；情绪高潮动作单独成段（"他没有进去。"式骤紧）；动作链>4 个拆成两段。

**5. 场景描写段**：1-3 句。并列元素≤4 个（超 4 拆段，按属性/空间分组）；每段≥1 个感官维度；同段感官维度≤3 个（超 3 拆段，优先留触觉嗅觉）；场景切换必拆段。

**导语段**：每个信息单元单句成段；总字数 80-150 字（导语可用句号/问号，不用感叹号；状语可单独成段）。

## 四、句号 vs 逗号（一张表定夺）

| 情况 | 句号 | 逗号 |
|---|---|---|
| 语义完整独立 | ✅ | |
| 语义未完，后面是补充/承接/转折/并列 | | ✅ |
| 前后同一语义单元 | | ✅ |
| 前后不同语义单元 | ✅ | |

十种常见错误（错→对）：
1. "她站起来。走进厨房。" → "她站起来，走进厨房。"（承接）
2. "他看了她一眼。没有说话。" → "他看了她一眼，没有说话。"（补充）
3. "我不知道。你在说什么。" → "我不知道你在说什么。"（对话内部）
4. "她蹲下去。没有碰它。只是看着它。" → "她蹲下去，没有碰它，只是看着它。"（同语义单元）
5. "他不知道她叫什么。但他认得她的背影。" → "他不知道她叫什么，但他认得她的背影。"（转折）
6. "她从来没拿过。因为觉得不合适。" → "她从来没拿过，因为觉得不合适。"（因果）
7. "三年了。她习惯了那束花。" → "三年了，她习惯了那束花。"（时间状语并入主句）
8. "碰到了一样东西。一颗纽扣。" → "碰到了一样东西，一颗纽扣。"（总起与补充）
9. "没有纸条。没有收件人。" → "没有纸条，没有收件人。"（并列短句）
10. "周末。我一个人去的。" → "周末，我一个人去的。"（时间状语单独成段）

**例外**：时间状语本身有情绪重量或就是核心悬念时可单独成段（"三年了。她数了一整个夏天的砖。"——出现在情绪高点 + 失踪三年是核心悬念，成立）。

## 五、禁止事项（语法 + 语感）

| 禁止项 | 错误示例 | 正确示例 |
|---|---|---|
| 时间/地点状语单独成段 | 周末。 | 周末，我一个人去的。 |
| 单字/单词成段 | 笑。 | 他在笑。 |
| 引导语单独成段 | 我低下头。说："好。" | 我低下头，说："好。" |
| 并列描写用句号拆 | 白的。软的。没有味道。 | 白的，软的，没有味道。 |
| 段落以逗号结尾 | 我抬起头，看着她， | 我抬起头，看着她。 |
| "但是"开头起段 | 但是我咽下去了。 | 但我咽下去了。 |
| 书面腔连接词 | 由于当时情况过于突然…… | 太突然了。我没想到后面会那样。 |
| 抽象情绪词 | 她心如刀割。 | 她低头看见手腕上那圈淤青。 |
| 翻译腔（欧化句式） | 他被这个突如其来的决定所深深地影响了。 | 这个决定砸下来，他三天没说话。 |
| 解释性语言 | 那一刻她终于明白了。 | 她没有哭，但手在抖。 |

## 六、语感三条底线

**底线一 · 口语的真实感**
- 视角锁定：不写主角不知道的事（"他看着我，不知道说什么"是偷看内心 → 改"他看着我，没有说话"）。
- 写完出声念一遍，卡顿处就是问题。
- 虚词控制：不替角色说感受，只写动作+物件（"她很孤独" → "她数了一整个夏天的砖，一共四十七块"）。
- 禁书面连接词（由于/因此/然而/于是/然后），短句并列即可（机检只数 然后/接着/之后 起段 ≤3 处、目标 0——check-metrics 第 6 项；因此/然而另走 check-ai 密度项，由于/于是靠人工）。
- 禁解释性语言（"终于明白/意识到"），写"她没有哭，但手在抖"。

**底线二 · 信息的密度**
- 单句≤25 字；金句 15-25 字、每 500-800 字一处；连续 800 字无金句 → 补。
- 每段≥1 个感官维度，纯视觉段补声音/气味/温度/触感。
- 抽象情绪词（绝望/痛苦/悲伤/无奈）**逐词限量 ≤2 处**（对齐 AT-36：计数单位是单个词种，不是四词合计），每处须接动作/物件；裸用即改（"她心如刀割"→"她低头看见手腕上那圈淤青"）。
- 比喻风格统一：前面全实就不要突然来虚比喻。

**底线三 · 节奏的流畅度**
- 同一段同一非核心词出现>2 次 → 换；同一句式同一页>2 次 → 改（连续 3 句同一主语开头必改）。
- 结尾收束力：最后 300 字落具体意象。

## 七、视角转换分段（第一人称专属）

| 感知组合 | 分段 |
|---|---|
| 看见+听见（同一场景） | 同段或拆段均可 |
| 看见+内心活动（同一瞬间） | 必须拆段 |
| 听见+回忆（时间转换） | 必须拆段 |
| 看见+身体感受（同一瞬间） | 可同段 |

## 八、情绪节奏 ↔ 段落长度对照

| 情绪节奏 | 段落形态 | 场景 |
|---|---|---|
| 极快 | 对话段/1 句段 | 对峙、争吵、真相揭露 |
| 快 | 1 句段 | 关键动作、突发事件 |
| 中速 | 2-3 句段 | 场景描写、心理活动 |
| 慢 | 3 句段 | 情绪累积、铺垫 |
| 停顿 | 单句独段 | 金句、沉默、余味 |

忌通篇同长度段落（同一字数切段是 AI 腔铁证）；忌通篇短句电报体（独句段≠电报体，句子内部不碎）。

## 九、AI 腔句式禁令（写作时直接规避）

1. "不是 A，而是 B"二分壳 → 拆成两句陈述。
2. "仿佛/宛如/在那一刻/紧接着" → 换具体感官细节。
3. 句尾"……，他终于明白了一切"式感悟补语 → 删掉，让动作说话。
4. 开头"在……的……里" → 直接从动作/对话/冲击事实起笔。
5. 连续等长句、每段金句收尾、起承转合太对称 → 打破节奏。
6. 禁用词：赋能、闭环、抓手、颗粒度、底层逻辑、不可否认、值得注意的是、总而言之（黑话与套话）。
7. 情绪词两级口径：**直给级**（绝望/痛苦/悲伤/无奈等普通情绪词）**逐词 ≤2 处**（同一个词最多 2 次，四个词各 2 次合规），每处必须接一个此刻特有的具体动作或物件（"心更冰冷了。汤上面还浮着凝固的油，根本喝不了。"）；**陈词滥调级**（心如刀割/心如死灰/五雷轰顶等被用滥的比喻式情绪词）一律替换为具体动作或物件，禁直接使用。机检面对应 check-ai EMOTION 词表（直给级逐词 ≤2、陈词滥调级 = 0），两级同源不打架。

## 十、完整自查清单（三遍 20 项，每章写完执行）

## 十一、约束冲突裁决表（规则打架时查这张表，别犹豫）

规则多必有撞车处，以下裁决点已穷举常见情况——**裁决原则：保读者体验 > 保量化指标**：

| 撞车的两条规则 | 裁决 |
|---|---|
| 字数门不足 vs 禁注水 | 按节拍补"动作-反应+感官+对话"；宁可整节重写，禁碎片插入与注水 |
| 金句每 500-800 字一处 vs "段段金句=廉价" | **只埋五大必埋位**（导语尾/前1/3尾/中段转折/后段击穿/尾声），其余密度让位于自然 |
| 钩子密度 vs 断点自然 | 节末钩必须有（≥7 个/万字）；微型钩不硬塞，宁缺勿刻意 |
| 情绪浓度（300 字红线）vs 流水账 | 红线是底线不是凑数令——用节拍升级而非硬造冲突过线 |
| 克制写实 vs 赛道渲染 | 按 kill-ai 4.0 分赛道润色档（克制/平衡/释放），情绪峰值段以段为单位豁免 |
| 对话占比 vs 叙事驱动题材 | 机检带 [18%,45%]（1514 篇实测，均值 25.8%）；甜宠/口述感赛道目标带 40-50%；查对话戏是否缺失，禁凑比 |
| 独句段≥30% vs 电报体 | 长短交错；独句段攒到 3 连排就该合并一句 |
| 去 AI 改写 vs 信息守恒 | 取"更贴近原意且更朴素"的一版；保护清单兜底 |
| 润色精简 vs 盐选招牌句 | 招牌句（金句/钩子/击穿句）不动，只在招牌句之外精简 |
| 节律快慢 vs 单章字数档 | 全文统一一种节律；单章走 1800-2800（AT-02；情绪拉扯章可放宽至 2800-3500，须在细纲注明），节律靠章内场景切换频率调节，不靠压缩字数 |
| 三称稿 vs 一称锁定 | 三称稿（输入显式声明）下润色"不换人称"优先；一称锁定是缺省设定，一称感知参考项对三称稿不适用 |
| 外部"每段 50-80 字"口径 vs 1514 篇语料三档 | 50-80 是理想带的子区间（51-80 两者同时满足）；对外部口径敏感的稿源可收严至"≤80 字必修"，缺省维持语料校准三档（≤50 理想/51-100 警示/>100 必修） |
| 用户口味 vs 技能默认 | **用户显式要求 > 技能规则**（确认门的拍板权高于一切数字门） |
| 公式合规 vs 神来之笔 | 每篇 **1-2 处破格配额**（见第十三节）：经确认门拍板的破格不判违规，审稿不得以格式项扣分 |

## 十二、口诀（贴在写作现场）

```
对话单段一句完，金句独立才能站。
叙述最多三句话，动作看节奏快慢。
状语并入不单列，并列描写逗号连。
五十字数上限限，卡就拆段不手软。
单句太长要拆分，逗号结尾不能干。
长词开头书面感，短词才上盐选船。
直角引号是硬规，千万莫用双引号。
语义断则句号，不断则逗号。
虚词一删动作补，一段一感官。
八百字内一金句，最后三句落意象。
```

## 十三、破格配额（纯按公式产出的上限是"合格"）

全部硬规全绿的稿子是"标准件"，编辑读完记不住。**每篇预留 1-2 处破格**，让稿子有"人写的"指纹：

1. **什么算破格**：一处违反风格硬规但服务情绪的句式（如情绪峰值故意用一个超长句/一次破折号）、一个不按十三式走的章尾钩子、一处"不划算"的闲笔（对情节无用但立人物的细节）、一个偏离标题公式的标题——**服务于情绪与人物的越界**才算破格。
2. **什么不算**：P0 格式硬伤、题材红线、视角跳动、伏笔断裂**永远不在配额内**——破格是风格层特权，不是质量门豁免。
3. **流程**：破格处必须在 `02-细纲.md` 上篇施工版登记"破格预算"（位置 + 破了哪条 + 为什么值）→ 用户确认门拍板 → 审稿时对登记过的破格**豁免对应格式扣分**（在审稿报告标注"已登记破格"）。
4. **上限 2 处**：超过 2 处 = 失控，按违规处理；破格必须比合规写法**更强**，"差不多"的破格是纯风险，退回合规版。
