# 结构指纹与同质化防线（fingerprint.md）

> 供七步法**阶段 1**（登记计划指纹）与**阶段 7 / 复盘**（实落回填 + 跨篇比对）使用。指纹 glob 适配 `08-结构指纹.md` 命名，AT 编号以 authority-table.md 为准。
> 解决的问题：技能早设了「连续 3 篇不得同一故事模式」（AT-46 红线），但这条红线一直是**靠人的记忆事后判**——必然失守。

## 一、为什么需要它

一次隔离实测里，4 篇创作样本（书房/署名/薄荷糖/看海）不约而同落入**同一结构模板**：第一人称限知 + 隐忍取证 + 冷发现 + 当众打脸。题材变量换了（婚姻/职场/校园），可**结构指纹高度相似**。

人的记忆在"我上周写过什么"上极不可靠，红线就形同虚设。解法是把"故事模式"从**只能感觉**变成**可以比对**——把它抽象成 6 个维度、每维一个**封闭枚举值**，再用脚本跨篇两两比对。

> 口径对齐：本判定与 `genre-map.md` 4.1「结构指纹登记」同源，只是把可比的维度从"设定/身份/反转/意象"规范化成固定的 6 维。

## 二、六维结构指纹（封闭取值）

每篇选一个候选，六维各填**一个**枚举值（落在枚举内，便于跨篇严格比对）：

| # | 维度 | 枚举取值 | 说明 |
|---|---|---|---|
| 1 | 叙事起点 | 反常发现 / 身份困境 / 倒叙悬念 / 绝境求生 / 交易开局 / 觉醒复仇 / 悬疑惊悚 / 时空错位 | 开篇第一句靠什么起钩 |
| 2 | 主角行动模式 | 取证反击 / 隐忍蓄力 / 主动布局 / 逃离自救 / 以退为进 / 正面硬刚 / 旁观揭底 | 主角"做"的方式（不止"发现"） |
| 3 | 核心反转类型 | 身份/关系反转 / 动机反转 / 时空反转 / 认知框架反转 / 叙述者不可靠 / 无反转（报应兑现） | A 级反转的机制 |
| 4 | 核心意象类别 | 器物信物 / 场景空间 / 身体印记 / 文本记录 / 气味食物 / 自然天象 | 信物道具的类别 |
| 5 | 关系翻转方向 | 受害者→清算者 / 弱者→强者 / 被弃→被追悔 / 陌生→羁绊 / 局中人→揭局者 / 无翻转 | 权力/情感关系的走向 |
| 6 | 付费卡点触发情境 | 认知颠覆时刻 / 身份揭穿瞬间 / 生死悬念顶点 / 情感决裂 / 真相反转将发未发 | 免费区结尾断在哪种情境 |

### 2.1 六维设计说明（为何不扩维）

同质化防线常见的扩展维度（金手指/信息差、反派动机、情绪曲线、结局类型）本表**不收编**（扩维牵动 check-fingerprint.py 与跨篇台账，破坏面>收益），由既有检查承载：

| 常见扩展维度 | 技能承载 | 说明 |
|---|---|---|
| 开篇冲突类型 | 维1 叙事起点 | 直接对应 |
| 反转类型 | 维3 核心反转类型 | 直接对应 |
| 卡点位置 | 维6 付费卡点触发情境 | 直接对应（触发情境 + 字位由 AT-04/AT-05 管） |
| 金手指/信息差 | 维2 主角行动模式 + `stage3-outline` 黄金三章线索位 | 近似对应 |
| 反派动机 | `stage3-outline` 人设卡"对手动机必须可理解，禁止纯坏" + 配角独立动机句 | 机制检查承载，不进指纹枚举 |
| 情绪曲线 | AT-58 缓爆交替 + 同情绪不连 3 章（`stage2-synopsis` 情绪弧线） | 规则检查承载 |
| 结局类型 | 梗概卡情绪弧线 + `stage2-synopsis` 字段 8「结局走向」 + style-rules 结尾（最后 300 字落具体意象） | 规则检查承载 |

**判定口径声明**：本技能同型判定只认 AT-48"两篇 ≥2 维重合=同型（机检自动预警）"一套口径——技能内报告、机检输出、复盘台账三处同口径，不引入第二套宽严尺互算。

## 三、判定口径

- **两篇指纹在 ≥2 个维度取同一枚举值 = 同型**（本技能判定阈值，`MIN_OVERLAP = 2`）。
- 同型若落在**连续 3 篇**窗口内 = 命中 **AT-46 红线**（连续 3 篇不得同一故事模式）→ 回阶段 1 **换模式重出选题**（出题轮 ≤2，AT-51）。
- **单维重合不判同型**——换一条赛道 / 换一类意象，已足够差异化。
- 该红线**不在"破格预算"内**（每篇 1-2 处破格配额不能用来豁免同质化）。

## 四、工作流

1. **阶段 1**：选定候选后，随 `00-选题评估.md` 一并落盘 `08-结构指纹.md`（模板见 `../../templates/08-fingerprint.md`）。
2. **阶段 7 / 复盘**：用 `scripts/check-fingerprint.py` 与近作指纹比对。
   - 传目录 → 自动递归收集 `**/08-结构指纹.md`；
   - 传文件 → 直接比对给定的几篇。
3. 命中预警 → 回阶段 1，**换 ≥2 个维度**重出选题。

## 五、机检

```bash
python3 scripts/check-fingerprint.py <项目父目录 | 08-结构指纹.md ...>
```

退出码：`0`=无同型；`2`=存在同型预警（⚠️）；`1`=用法错误或六维未填全。
