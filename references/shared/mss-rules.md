# MSS 机检结构分规则（mss-rules.md）

> 本文件是 MSS 机检结构分的规则落地，与 `scripts/check-mss.py` 实现逐条对齐（改口径必须同改两者并跑回归）。
> 定位：**只做机检结构匹配，不预测真实过稿，不预测爆款。** 供阶段 6（6a 结构化评审）调用；阶段 4 全篇核验可提前预跑。
> 规律库基线：现行规律库（基线有效期管理见第七节）。

## 〇、总则与输出纪律

**能评什么**：形式合规 / 标题导语梗概金句字段 / 开篇卡点章末结构位置 / 密度代理 / 伏笔回收与承诺兑现 / 红线词待核提示。

**不评什么**（不进评分、不出评分结论）：语言风格与文学性、情绪外化质量、潜台词质量、去 AI 味与 AI 结构指纹、代入感、人设记忆点、反派动机、结局余味、真实读者反应、编辑过稿、付费意愿、爆款概率、双评审与主编直觉。部分不评项以"待人工复核清单"弱代理提示，仅提示、不计分、不改 MSS。

**输出纪律（五条，机检报告必须遵守）**：
1. 结论只写"机检结构匹配"，不写"过稿评估""爆款预测"；
2. 禁止表述"保证过稿""必爆""确定能过"；
3. 所有关键词匹配必须输出命中词、位置、窗口、上下文片段——无上下文片段不计分；
4. 红线词命中只输出"待核提示"，不输出合规结论；
5. 所有评分项必须可复算，给出分子/分母或窗口位置。

## 一、必须输入（缺一即报缺，禁猜测代填）

| # | 输入 | 口径 |
|---|---|---|
| 1 | 正文纯文本 | `--text <文件>`；分节必须纯数字（1/2/3 独立成行，不带点/括号等任何符号） |
| 2 | 标题 | `--title`，≤20 字（AT-24 三档） |
| 3 | 导语 | `--intro`，80-150 字（AT-06） |
| 4 | 一句话梗概 | `--logline`，≤50 字（AT-42 机检场景） |
| 5 | 金句列表 | `--quotes`，3-5 句、每句 ≤40 字（`\|` 分隔） |
| 6 | 伏笔回收表 CSV | `--foreshadow`，五字段：埋设位置/埋设原句/回收位置/回收原句/回收方式 |
| 7 | 卡点标记 | 显式 `[[首锁]]`/`[[二锁]]`；或用 `--paywall` 锚句等效（卡点双口径，AT-05） |

> 调用纪律：`--text` 为必需参数，无位置参数；标题/导语/梗概/金句显式传入（正文内不拆字段）。
> 伏笔表五字段即细纲六表"伏笔规划表"的直接导出（见 stage3），完稿回收原句须与正文逐字一致。

## 二、评分公式与分档

```
MSS = F + B + T + D + R   （满分 100）
```

| 模块 | 权重 | 内容 |
|---|---|---|
| F 形式 | 30 | 总字数、分节格式与编号、段落 ≤50 字占比、平均句长、对话「」、半角标点、一称"我"频率 |
| B 标题导语梗概金句 | 20 | 标题长度/标点/冲突词、导语字数与首句冲突、梗概字数与冲突词、金句数量与字数 |
| T 结构位置 | 25 | 开篇 100 字冲突共现、前 300 字钩子/困境、首锁字位、卡前 200 字情绪词、卡后 300 字钩子、章末动作钩/新问题 |
| D 密度代理 | 15 | 情绪词密度、推进/反转词密度、打脸词密度、新名词性词、钩子类型轮换 |
| R 回收兑现 | 10 | 伏笔回收率、标题/导语核心词前 3000 字兑现 |

**分档（AT-66）**：≥80 高匹配 ‖ 60-79 低匹配 ‖ <60 不匹配。
**硬门未过：MSS 封顶 59**（见第三节）。红线词命中：只输出待核提示，不影响评分但须人工核。

## 三、12 项可机检硬门（任一触发 → 封顶 59）

| # | 硬门 | 口径 | 对应 AT |
|---|---|---|---|
| 1 | 总字数 | 12000-16000 字（越界即硬门） | AT-01 |
| 2 | 标题字数 | >20 字 | AT-24 |
| 3 | 标题标点 | 含问号/感叹号 | AT-24 |
| 4 | 导语 | 不在 80-150 字 | AT-06 |
| 5 | 段落合规率 | ≤50 字段落 ÷ 总段落 <60% | AT-63 |
| 6 | 对话符号 | 未使用「」 | 形式硬规（style-rules 一） |
| 7 | 分节格式 | 未用纯数字分节（1/2/3 独立成行）、或混用"第x章/第x节"、或跳号/重复/倒序、或分节数 <3（**节数只认从 1 起连续递增的分节序列**——正文中孤立成行的数字如年份/金额不计为节） | 形式硬规（style-rules 一·章节标题条） |
| 8 | 卡点标记 | 缺失，或首锁偏离全文 25%-35%（字位 3000-4000） | AT-04/AT-05 |
| 9 | 伏笔回收表 | 缺失，或回收率 <80% | AT-22 |
| 10 | 开头共现 | 开头 100 字无冲突/动作/代词/后果词共现（≥2 类） | AT-40 |
| 11 | 章末动作钩 | 连续两章章末无动作钩 | AT-30/AT-45 |
| 12 | 核心词兑现 | 标题/导语核心词在正文前 3000 字未出现 | AT-65 |

**强提示项（不硬门，重扣分）**：前 500 字无第一人称"我"（AT-64）‖ 一句话梗概缺失或 >50 字 ‖ 金句少于 3 句或多于 5 句 ‖ 半角标点比例 >10%（AT-17）‖ 二锁标记缺失或未产生新悬念。

> 注：开头共现门取 **100 字**（严于平台"300 字爆炸点"口径）——过稿/爆款导向下前三行即需冲突标记共现，100 字门更安全；四类词表（冲突/动作/代词/后果）与 ≥2 类阈值以 4.3 明细表和 check-mss.py 实现为唯一标准。
>
> **共现判定精度条款（防假阳性）**：四类词**不等权**——`冲突词` 与 `后果词` 是实质类，`动作词` 与 `代词` 是辅助类。**辅助类凑够两类不判过**（"我叫林晚…出门坐地铁上班"同时命中「我」与「出」，却是纯身份陈述式平开头，正是编辑最常拒的第一类）；须有 ≥1 个实质类支撑。冲突词表已含**物证型/异常型**（解约/遗嘱/诊断书/亲子鉴定/监控/失踪/不见了等）——盐选大量开头是"静物异常"而非人际当场对撞，只收人际冲突词会把真爆款式开头误判为平铺。

## 四、逐项口径表

### 4.1 标题 / 导语 / 梗概 / 金句（B 模块计分面）

| 项 | 标准 | 机检方式 |
|---|---|---|
| 标题长度 | ≤15 字最佳；16-20 字合格；>20 字硬门 | 字符统计 |
| 标题标点 | 无问号/感叹号 | 正则 `[？?！!]` |
| 标题冲突 | 含冲突词/对立词/情绪反差词 | 词表共现（加分项，不硬门） |
| 标题过短 | <5 字提示"信息量不足" | 字符统计 |
| 标题核心词 | 在正文前 3000 字出现 | 关键词匹配（硬门 12） |
| 导语字数 | 80-150 字 | 字符统计（硬门 4） |
| 导语首句 | 含冲突词/悬念词 | 词表匹配 |
| 导语核心词 | 在正文前 3000 字出现 | 关键词匹配 |
| 梗概字数 | ≤50 字 | 字符统计 |
| 梗概内容 | 含冲突词/悬念词 | 词表匹配 |
| 金句数量 | 3-5 句 | 列表统计 |
| 金句每句字数 | ≤40 字 | 字符统计 |

### 4.2 形式（F 模块计分面）

| 项 | 标准 | 机检方式 |
|---|---|---|
| 总字数 | 12000-16000 字 | 字符统计（中文字符+标点，不含空白与 Markdown 标记） |
| 分节符号 | 纯数字分节（1/2/3 独立成行） | 行首正则 `^\s*\d+\s*$` |
| 编号顺序 | 从 1 连续递增 | 编号序列提取 |
| 分节数量 | ≥3 节 | 分节标记统计 |
| 混用格式 | 禁"第x章/第x节" | 正则 `第[一二三四五六七八九十\d]+[章节]` |
| 段落 ≤50 字占比 | ≥60%（硬门 5）；≤30 字 ≥60% 推荐优秀 | 按换行切段统计 |
| 平均句长 | ≤25 字 | 按句末标点切分 |
| 对话符号 | 必须「」 | 正则扫描 |
| 半角标点占比 | ≤10% | 半角逗号/句号/引号 ÷ 总标点 |
| 一称"我"频率 | 前 500 字 ≥5 次达标；≥8 次优秀 | 字符统计 |
| 首锁位置 | 全文 25%-35% | 字符位置计算（与 AT-04 字位口径双口径并行，AT-05） |
| 二锁位置 | 首锁之后且产生新悬念 | 位置+关键词去重 |

### 4.3 结构位置（T 模块计分面）

| 项 | 机检方式 |
|---|---|
| 开篇 100 字冲突标记 | 冲突词+动作词+双方代词+后果词共现（≥2 类） |
| 前 300 字钩子标记 | 悬念词/信息差词扫描 |
| 前 300 字核心困境 | 困境词扫描 |
| 卡点前 200 字情绪词 | 情绪词密度 |
| 卡点后 300 字钩子 | 钩子词扫描+类型去重，≥3 且类型不同 |
| 每章末 100 字动作钩 | 动作动词/疑问/省略号/未解词，且不含总结抒情词 |
| 每章末 200 字新问题 | 疑问句/未知词，且与上一章关键词去重 |
| 连续两章无动作钩 | 序列检测（硬门 11） |

### 4.4 密度代理（D 模块计分面）

| 项 | 机检方式 |
|---|---|
| 情绪拐点词密度 | 每千字 0.8-1.2 个情绪词（AT-35 机检代理——可指认拐点人工核以此条为准） |
| 推进/反转词密度 | 每 300 字窗口 ≥1 |
| 打脸/爽点词密度 | 每 600 字窗口 ≥1 |
| 每 2000 字新名词性词 | 词性标注后统计首次出现 ≥2 |
| 钩子类型轮换 | 按词表分类去重，轮换率 ≥60% |

> 密度代理双口径声明（AT-67）：工具口径（300/600/2000 字窗口）管机检匹配，技能钩子密度口径（AT-27 微钩 500 埋设/600-800 验收、AT-28 小钩 1500、AT-29 认知反转 3000）管创作节奏——两口径并行不互斥、不可互算，报告双写。

### 4.5 回收兑现（R 模块计分面）

| 项 | 机检方式 |
|---|---|
| 伏笔回收表 | 作者提供 CSV 五字段（见第一节） |
| 回收率 | 回收条目 ÷ 埋设条目 ≥80%（目标 100%） |
| 承诺兑现 | 标题/导语核心词在正文前 3000 字内出现 |

缺伏笔回收表或回收率 <80% = 硬门 9。

### 4.6 红线与异常提示（不计分）

红线词扫描（涉政/涉黄/涉暴/自杀自残/校园霸凌/性别对立/地域歧视/医疗伪科学/法律伪常识等）；"XX%"百分比断言且无来源标注；赛道粗分类（现实情感/生活化悬疑/脑洞短篇/言情甜虐）。机检只能提示"命中红线词"，不能判定是否真实违规——命中时输出"待核提示"，不输出合规结论。

## 五、待人工复核清单（B1-B12，不计分、不改变 MSS）

机检弱代理只提示、不评价：不计入 F/B/T/D/R、不影响评级、不触发硬门与红线。触发规则：

| # | 项 | 触发条件 | 人工复核点 |
|---|---|---|---|
| B1 | 情绪外化不足 | 情绪词后 15 字内无动作动词/物件名词/身体反应词 | 是否空泛心理描写 |
| B2 | 潜台词不足 | 对话「」结束后紧跟 ≥2 个解释性词（因为/所以/其实/说明/表示/意味着/也就是说） | 是否把对话已表达的意思又解释一遍 |
| B3 | 代入感弱代理 | 前 500 字"我"达标但感官词密度低于阈值 | 是否缺具体场景、身体感受、环境细节 |
| B4 | 人设记忆点弱代理 | 前 500 字主角标签词重复 <2 次或无强特征词 | 是否有可复述标签、口头禅、行为习惯、身份反差 |
| B5 | 反派动机弱代理 | 反派首次出现后 500 字内无目标词/因果词/动机词 | 反派是否有目标、理由、代价、逻辑链 |
| B6 | 结局余味弱代理 | 最后 200 字无留白词/情绪落点词/讨论点词，且以总结词结尾 | 结尾是否可讨论、可回味、有情绪落点 |
| B7 | AI 结构味弱代理 | 句长方差偏低，或连接词密度偏高，或段落长度方差偏低 | 是否有节奏变化、口语感、拧巴感 |
| B8 | 语言风格弱代理 | 平均句长合规但词汇丰富度低或修辞词密度低 | 是否有画面感、节奏感、个人风格 |
| B9 | 反转质量弱代理 | 反转词出现但前 300 字无暗示词 | 反转前是否有 ≥2-3 处暗示 |
| B10 | 打脸质量弱代理 | 打脸词出现但前 300 字无铺垫词，或后 100 字无代价词 | 打脸是否有铺垫、有代价、有后果 |
| B11 | 钩子质量弱代理 | 章末钩子词出现但前 500 字无对应铺垫词 | 钩子是否有前文依据、与主线强相关 |
| B12 | 承诺兑现弱代理 | 核心词前 3000 字出现但仅 1 次且位置靠后 | 核心承诺是否在前 3000 字充分展开 |

**与 MSS 的关系**：待人工复核项触发与否、数量、严重度、是否解决——**均不影响 MSS、分档、硬门、红线**。MSS 只由 F/B/T/D/R 计算；硬门只由第三节列表决定；红线只由红线词扫描决定。B1-B12 清单是阶段 6 六维打分、18 维终审与红队的输入线索（见 stage6）。

## 七、规律库版本管理与回归

| 项 | 口径 |
|---|---|
| 规律库基线 | 现行基线（随报告输出） |
| 有效期 | 基线设有效期管理；到期未更新则机检报告标注"⚠️ 规律库待更新" |
| 回归测试 | `tests/run-tests.py` 固定对拍：金标准 mss-good（MSS≥80、机检匹配高、无封顶）+ 坏样 mss-bad（封顶 59、≥5 硬门） |
| 多次生成回归 | 固定模型、温度、top_p、随机种子、系统提示、输入哈希；核心 n≥5、探索 n≥3 |
| 漂移处置 | 报告均值/SD/最好最差；方差 >2 触发复测或综合分降 0.5-1——防规则静默漂移 |

## 八、与七步法的接线

1. **阶段 4**：全篇核验第 3 项双锚句实测后，可预跑 check-mss 提前发现结构问题（非门禁，门禁在阶段 6）；
2. **阶段 6 · 6a**：`check-all.py` 一键门内含 check-mss；机检数字报告进审稿材料包六件（标注稿不进人审视野，以机检数字报告替代计数源）；
3. **口径权威**：本文件数值与 authority-table.md（AT-66 MSS 五模块/12 硬门、AT-67 密度代理、AT-68 热度四指标）冲突时，以 authority-table.md 为准并回改本文件与 check-mss.py；
4. **效果边界**：机检保护 L1 形式合规 + L2 结构合格，不保证 L3 出彩过稿——机检全绿 ≠ 能过稿（见 SKILL.md 1.3 效果边界声明）。
