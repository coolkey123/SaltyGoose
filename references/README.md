# references/ — 流程规则总览与加载索引

> **本文件是 references 树的入口**：七阶段门总表（一页速查）+ 常见门禁失败路由 + 按阶段加载索引 + 红线/参考分级与完读率三环。
> **"不过不前进"总纪律**：任一环节产物未落盘或门未过，禁止进入下一阶段。质量门 ≠ 确认门：质量门是机器/清单验收；确认门是用户拍板（①②③④共四道，AT-52），两者互不豁免。
> 数字口径一律以 `shared/authority-table.md`（AT-xx）为唯一权威；脚本不可用时按降级条款人工执行同一标准，标"⚠️ 人工核验（脚本降级）"——**降级不降门**。

## 二、常见门禁失败的路由（跨阶段现象表）

| 现象 | 根因阶段 | 处置 |
|---|---|---|
| MSS 硬门 5/7 触发（段落/分节） | 阶段 4 写作 | 回对应章按 `shared/style-rules.md` 切段/分节重写 |
| MSS 硬门 8（首锁字位）或 AT-04 偏离 | 阶段 3 细纲 | 付费点前移或加厚卡前章；禁挪卡点句凑位 |
| 伏笔回收率 <80% | 阶段 3/4 | 补埋或删埋（对六表复点） |
| check-ai exit 2 | 阶段 5 润色 | 按 `shared/kill-ai.md` 四层清单改到 exit 0 |
| 18 维对比锚定判"更弱" | 阶段 6 内容层 | 不得给 8 分以上；回根因阶段 |
| 相似度 ≥25% | 阶段 1/3 | 一票否决，回阶段 1 换模式重出 |
| 同型预警（指纹 ≥2 维重合） | 阶段 1 选题 | 换 ≥2 个维度重出；连续 3 篇同模式触 AT-46 红线 |

> 本表是**跨阶段现象**的速查——相似度 ≥25% 回阶段 1、18 维判弱回阶段 6 内容层，现象本身跨阶段，故留在本总览而不拆进单一阶段 self-check；各阶段 self-check 只放本阶段脚本调用与清单。

## 三、红线项与参考项的分级执行（防"压线堆砌"）

| 级 | 范围 | 执行纪律 |
|---|---|---|
| **红线项（硬门，不过不前进）** | 总字数带、付费墙字位、导语字数（含三要素 AT-71）、段落合规率 ≥60%、对话「」、分节格式、伏笔回收率 ≥80%、首锁字位、双打分 ≥25/均分 ≥8、黄金三章要素位、名场面 ≥1（AT-69）、卡点三型（AT-70）、闭环章数上限（AT-72）、主疼位指认（AT-73）、75 项 P0 全项 | 压线即改，无浮动 |
| **参考项（目标值，防过载）** | 钩子/靶点/金句密度类、独句段 ≥30%、虚词计数、一称感知占比 | 允许 70%-130% 浮动；单项不足先对照全文节奏判断；**禁止为凑指标堆密度**；连续 2 项以上偏离带宽才需修 |

**反节拍器警报（红线项之外的负向门）**：参考项全部"刚好压线达标" + 钩子/靶点/段落长度呈机械均匀分布 = 结构层 AI 味，判 S2 打回（修法：打乱节拍、留一处"不划算"的闲笔，不是再加指标）。

**完读率代理三环（AT-77，多源印证）**：审稿 6b 须显式核三环（细则见 `stage6-review/workflow.md` 终审工序 5）——①开环·首锁前三连击（AT-18，参考项）②中环·中卡点 45-55%（AT-10，红线项）③闭环·**结尾前 500 字禁总结词收束**（末段落具体动作/画面/留白；机检 B6 最后 200 字是弱代理，两者分层不互替）。
