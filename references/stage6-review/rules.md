# 阶段 6 · 初审与终审 — rules（必须遵守什么）

> **本文件回答：有哪些约束、必须遵守什么。** 本阶段特有规范与禁令在此；全库通用红线见 `../../assets/compliance-redlines.md`（唯一正本）；术语口径见 `../shared/authority-table.md`。

> **R 编号命名空间**：本文件的 R1~Rn 只在本阶段内有效——其他阶段的 R 编号是各自 rules.md 的独立序列（如 R12 在阶段 5 指净稿冻结、在阶段 6 指待核项禁假合格）。**跨文件引用 R 编号必须带阶段名**（写「stage6 R12」或「阶段 6 规则 R12」），裸写「R12」视为无锚引用。

## 一、审稿人纪律（必守三条）

| # | 规则 | 违背后果 |
|---|---|---|
| R1 | **算术指控必须先复算**——指出正文数字/量级错误前，自己把单位换算与算式写一遍，算不出来的不许断言"作者算错" | 审稿人误判会误导作者把正确文字改错（实战教训：一石=十斗=一百升，原文量级本来是对的） |
| R2 | **发现问题与改稿分离**——审稿人不下场改，改由根因路由回对应阶段 | 审稿人顺手改 = 改动无留痕、无双版本、绕过上游门 |
| R3 | **"设计取舍"不得包装成"已解决"**——红队条目须逐条标真实缺陷/主动承担/建议，三档不得混写 | 混写会让"主动承担的风险"看起来像已修，终审结论失真 |

## 二、冷启动纪律（优先级最高）

| # | 规则 | 说明 |
|---|---|---|
| R4 | 审稿必须与写作过程隔离：①独立 sub-agent（不给写作过程）②隔会话审稿 ③退化兜底（隔 30 分钟以上并标注"⚠️ 同上下文自审"） | 凡对外给出评分/等级/是否可投判定，一律以①②的隔离结论为采信依据 |
| R5 | **未隔离审稿时 18 维门值收紧到 ≥8.8** | 防止"自己给自己放水"——同上下文自审天然宽松 |

## 三、结论与路由禁令

| # | 禁令 | 说明 |
|---|---|---|
| R6 | **禁写"能过稿""会爆"**——机检结论只写"机检结构匹配/不匹配"；机检全绿 ≠ 能过稿 | 效果边界：机检只验结构，不验市场 |
| R7 | **红线只提示待核**——不判死、不替平台表态；红线命中按 `../../assets/compliance-redlines.md` 一票否决 | 审稿人不是平台 |
| R8 | **每级回退最多 2 轮**（AT-51）——两轮仍不过：停下如实汇报卡点与候选处置，交用户裁决 | 禁无上限震荡回退 |
| R9 | **禁跳项、禁事后补登终审工序**——七道工序按序执行（删平台口径核验/相似度检测后重排），任一项不过即回退，逐条登记「终审工序执行记录」 | 跳项的工序在 check-process 面前必现形 |
| R10 | **终审层禁新设标准**——禁发明第 19 维或改权重；要改构成先改 AT-61/62/66/77 与盲测四维口径并登记 AT 表 | 防"6a 一套尺、6b 一套尺"双标漂移 |
| R11 | **盲测结论边界必须写明**——A 组胜只证明"比内部标准样例更抓人"，不证明能打赢当期榜上真作品；无外部对照时禁表述为"具备爆款相"；连内部对照源（`tests/golden/`）都不可用时，第 15-18 维记「⚠️ 未测」不计分，均分按已计分维折算，且禁出「可用」档结论（只能「需补信息（盲测对照源）」） | 内部对照胜利被当成爆款证据 = 自欺；无对照源还出可发结论 = 条件项假合格 |
| R12 | **待核项禁假合格**——任何核验/检测做不到时，按实际状态标注"⚠️ + 原因"，禁留空、禁把没做的事写成已做 | 占位符纪律，check-process.py 机器核。**沿革**：本条原锚定终审「平台口径核验/相似度检测」两项条件项，两项工序已删除；纪律本身通用化保留——投稿面条件项（平台当期规则）按阶段 7 口径执行，不再由初审/终审设联网核验工序 |

## 四、评分可复算

| # | 规则 | 说明 |
|---|---|---|
| R13 | **评分项可复算**——每项得分给出实测值 vs 门值；18 维每一维可追溯到口径来源 | 不可复算的分数 = 没打 |
| R14 | **关键词匹配必须输出命中词/位置/窗口/上下文** | 只写"命中"不写位置 = 不可复算 |
| R15 | **B1-B12 弱代理只进"待人工复核清单"**——不计分、不改 MSS | 弱代理计分 = 机检分数虚高 |
| R16 | 密度代理双口径并行不互算、报告双写（工具口径 300/600/2000 字窗 vs 技能钩子口径 AT-27 系） | 两口径混算 = 数字对不上 |
