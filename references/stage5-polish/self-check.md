# 阶段 5 · 润色 — self-check（该怎么自己检查）

> **本文件回答：该怎么自己检查。** 该干什么/怎么做见同目录 `workflow.md`；验收线见 `quality-gate.md`；禁令见 `rules.md`。
> 脚本调用口径（命令模板/退出码/⚠️ 人工确认流程）以 `../../scripts/README.md` 为唯一权威，本文件不复述。数值口径以 `../shared/authority-table.md`（AT-xx）为准。

## 一、脚本检查（机检）

| 检查项 | 跑什么 | 判据 |
|---|---|---|
| AI 味 | `check-ai.py`（靶点句所在章整章跑；全文跑一次） | exit 0；exit 2 按 kill-ai 四层清单定向改 |
| 收口尺子 | kill-ai Step 4 三把尺子（人工） | 五维 ≥35/50 + 六合一合格线 + AI 检测 12 项无 ❌ 且 ⚠️≤2；尺子 0 定删除预算 |
| 标注覆盖/靶点密度/节末钩 | `check-artifacts.py <项目目录>`（F/G 项） | 覆盖率 ≥90%（AT-14）；靶点密度 AT-33；钩子后缀 AT-45 |
| 双版本对账 | `check-artifacts.py` K 项 | 标注稿剥全部【…】标注后与净稿逐字一致；不一致报首处差异字位与双侧上下文 |
| 净稿清洁三扫 | `check-artifacts.py` L 项 | 编辑痕迹/逐字重复句/说明性尾注零命中；重复句命中须人工区分伏笔回看设计 |
| 字数带 | `check-length.py`（复核） | 12000-16000（AT-01）；<13000 触发缩水预警，核对删除预算 |
| 伏笔双标对账 | `check-artifacts.py` | 埋/收标与细纲伏笔规划表一致（AT-22） |
| 一键门 | `check-all.py <项目目录>` | 进阶段 6 前跑；净稿 ≥12000 字走整篇口径，不足走章级 `--fragment` 并标注 |

## 二、人工检查（词表层，机检不替代）

1. **kill-ai 四层清单逐句核**（靶点句所在章）——黑名单/破壁词 / 抽象情绪词两级逐词（AT-36）/ 弱化副词（AT-37）/ 虚词（AT-38）；
2. **21 招逐句过**——`../shared/kill-ai.md` 招式逐条对照；
3. **保护清单核对**——确认没误伤真实细节与靶点句（去 AI 味过度 = 把质感洗成白水）；
4. **复合式标注抽查**——七类是否全部复合式（单类写法机检静默归零）；伏笔双标描述是否写进括号内；
5. **净稿清洁三扫复扫**——L 项机检出可机检子集，人工复扫补盲区（编辑痕迹变体/重复句的伏笔设计内判定/尾注变体）；
6. **润色档核对**——克制强度是否符合本分赛道档位（克制/平衡/释放），情绪峰值段按档豁免，禁全篇一个力度。
7. **收口评分**——kill-ai Step 4 三把尺子人工过（五维/六合一/12 项），尺子 0 定删除预算并核对实际删除比例未超限。

## 三、常见自查失败的定向修法

| 自查不过项 | 定向修法 |
|---|---|
| 靶点密度/覆盖率静默算 0 | 先查标注是不是写成了单类 `【爽点】`——改为复合式 `【爽点+打脸】`，不是补标 |
| check-ai exit 2 | 按 `../shared/kill-ai.md` 四层清单定位到词，改到 exit 0 |
| K 项报双版本不一致 | 拿 K 项输出的首处差异字位定位——以标注稿为基准重生成净稿，禁手改净稿"追"标注稿 |
| L 项报逐字重复句 | 先判是不是伏笔回看设计内重复（是→人工确认保留并在报告记一笔）；不是→删重复句，禁两处一样还不自知 |
| 弱化副词超限（每千字 >3） | 删副词不改句意；删完句子立不住说明原句靠副词撑，回工序 A 重写该句 |
| 净稿有"修正:"残留 | S1 清稿——这是编辑痕迹混入投稿稿的直接拒项 |
| 净稿字数 <13000 | 缩水预警：核对删除比例是否超尺子 0 等级上限（轻 ≤15%/中 ≤25%/重 ≤35%），超限回工序 A 重写 |
