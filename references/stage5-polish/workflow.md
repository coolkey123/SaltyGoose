# 阶段 5 · 润色 — workflow（该干什么 + 该怎么做）

> **本文件回答：该干什么、该怎么做。** 验收线见同目录 `quality-gate.md`；自查口径见 `self-check.md`；禁令见 `rules.md`。
> Reference Gate：阶段 4 写作中与阶段 5 必读。数值口径以 `../shared/authority-table.md` 为准（AT-14/22/33/34/36/37/38/39）。
> 参照：`../shared/kill-ai.md`（四维诊断/21 招/黑名单/保护清单）、`../shared/style-rules.md` 段落三层自查。

## 一、做什么

两道工序一次完成——**先洗掉 AI 痕迹，再给情绪点打标注**，输出标注稿与净稿**双版本**。这是区别于普通写作流的增值工序。

## 二、工序 A · 去 AI 味 + 语言润色

**润色铁律**：完全保留剧情、人设和原意；只修语病、调句式节奏、精简冗余词；不大幅改写情节；文风克制写实、**不要堆砌华丽形容词**——克制强度按分赛道润色档执行（克制/平衡/释放三档，情绪峰值段按档豁免）。

### 靶点句（送检口径：所在章整章过 check-ai + 词表人工逐句核）

**靶点句** = 情绪峰值句 + 卡点句 + 金句 + 反转揭示句四类。靶点句所在章**整章过** `check-ai.py`（脚本为全文级，**无单句送检模式**——禁把单句拆成临时文件送检，那既绕过章级上下文又会污染包体），词表层面的逐句核对按 kill-ai 四层清单人工执行：

- **黑名单/破壁词**命中即返工（exit 2 不许带病输出）；
- **抽象情绪词**两级：陈词滥调级（心如刀割/五雷轰顶/心如死灰）=0 ‖ 直给级（绝望/痛苦/悲伤/无奈）**逐词 ≤2**（非四词合计，AT-36）；
- **弱化副词**（微微/淡淡/缓缓/轻轻）每千字 >3 = 超限必删（AT-37）；
- **虚词**（感到/觉得/很/非常/似乎/仿佛）短线 ≤10 处，长文降为参考（AT-38）；
- **情绪外化改写**：❌"我很绝望" → ✅"那只蜂蜜水还放在桌上，盖子没拧紧"（一个情绪只配一个可触摸锚点）。

**去 AI 味六步**：①四维诊断（黑名单/密度/禁用标点/破壁词）→ ②21 招逐句过 → ③黑名单清零 → ④破壁词密度 ≤0.5/100 字（AT-39）→ ⑤保护清单核对（不误伤真实细节与靶点句）→ ⑥复检 exit 0。

**收口尺子（kill-ai Step 4，三把尺子都要过）**：⑦尺子 0 六项客观指标定级（定删除预算：轻度 ≤15% / 中度 ≤25% / 重度 ≤35%）+ 尺子 1 五维评分 ≥35/50 + 尺子 2 六合一合格线 + AI 检测 12 项（无 ❌ 且 ⚠️≤2）。量化与主观冲突时以**人工计数**为准（允许 ≤1 档书面理由下调、不允许上调）；禁用词密度与对话标签密度无独立机检，按 check-ai 黑名单与对话标签腔命中数人工折算。此前本阶段只引 kill-ai 前四层（诊断/21 招/黑名单/保护清单），**验收核心（评分与合格线）零引用**——洗没洗干净没有尺子量，补此接线。

## 三、工序 B · 语义标注

关键情绪点后加方括号标注（七类），**必须写成复合式**——机检按字面精确匹配，写错格式会静默归零：

| 情绪类 | 复合标注（机检唯一认的写法） |
|---|---|
| 爽 | `【爽点+打脸】` |
| 悬念 | `【悬念+反转】` |
| 虐 | `【虐点+击穿】` |
| 甜 | `【甜点+升温】` |
| 笑 | `【笑点+反差】` |
| 泪 | `【泪点+来不及】` |
| 钩子 | `【钩子+留白】`，或章末带类型后缀 `【钩子·新问题/新信息/情绪转折/危险升级】` |

> **单类写法 `【爽点】` / `【悬念】` … 一律不计入**：`check-artifacts.py` 的 F/G 项按七类复合式精确计数，只写单类会让靶点密度与覆盖率**静默算成 0**，人排查时容易误判成"漏写靶点"而不是"格式错"（脚本现已对此显式告警，但不要指望它兜底）。

另按伏笔地图加**伏笔双标**（描述写进括号内，机检认前缀不认格式细节）：

- 首次落地标 `【伏笔·埋·Vx·一句话描述】`、回收兑现标 `【伏笔·收·Vx·一句话描述】`；
- 两标数量与细纲伏笔规划表对账：埋数=收数=地图条目数（回收率 ≥80%，AT-22）；**同一伏笔多处铺垫时，埋标数可多于地图条目数，多出的必是同一 Vx 的重复铺垫——若出现地图里没有的 Vx，才是真错**；
- **节末钩标注带类型后缀**（【钩子·新问题/新信息/情绪转折/危险升级】，AT-45），供 check-artifacts G3 同质化机检；
- **标注即机检计数源**：靶点密度（AT-33）与节末钩由 check-artifacts.py G 项按标注实测，**漏标即漏检**。

## 四、产物（双版本）

- `04-润色标注稿.md`——标注版（靶点/伏笔双标/节末钩类型后缀全在位）；
- `04-正文净稿.md`——去除全部标注的净稿（投稿用；阶段 7 投稿包唯一正文来源）。

模板与打包口径见 `../../templates/04-annotated.md`、`../../templates/04-clean.md`。

**双版本对账方法（门 4 的唯一执行口径，显式化）**：净稿 = 标注稿剥去全部【…】标注后的正文。对账跑 `check-artifacts.py <项目目录>` K 项——剥标注 + 引用/标题行 + 空白后与净稿逐字相等；发现差异**只许以标注稿为基准重生成净稿**，禁手改净稿"追"标注稿（手改即双版本漂移：投稿面与机检计数面从此对不上，且无留痕）。
