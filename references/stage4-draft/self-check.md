# 阶段 4 · 写作 — self-check（该怎么自己检查）

> **本文件回答：该怎么自己检查。** 该干什么/怎么做见同目录 `workflow.md`；验收线见 `quality-gate.md`；禁令见 `rules.md`。
> 脚本调用口径（命令模板/退出码/⚠️ 人工确认流程）以 `../../scripts/README.md` 为唯一权威，本文件不复述。数值口径以 `../shared/authority-table.md`（AT-xx）为准。

## 一、每章写作纪律与自查九条（写完即过，不过不进下一章）

每章写完逐条自查（1-9 全过再进下一章；6-8 为单章级，9 为脚本级）。**段落/句长/标点的细项统一走 `style-rules.md` 第十节「三遍 20 项自查清单」第一遍（段落结构）+ 第二遍（标点呼吸），查一遍即可，禁与本条重复过两遍**：

1. **章门字数**——本章 1800-3500 字（AT-03；常规档 1800-2800，情绪拉扯档 2800-3500 须细纲注明）；**第 1 章 2200-2800、第 2 章 2000-2800，两章禁取下限**（AT-79）；不足目标 70% 整章重写，**禁注水式扩句**；
2. **开篇专项门**（第 1 章）——首句 3 秒入戏、前 30 字报类型+强冲突、300 字内凑齐冲突+主角+悬念（黄金三章第 1 章的延伸要求）；导语另过导语专项门（三要素：反常识场景/身份悬念/未完成动作，末句将破未破，AT-71，见 `workflow.md` 第一节）；
3. **场景**——一章 2-4 场景、**一场戏一个场景**；
4. **对话**——对话占比 [18%,45%] 机检带（甜宠/口述感赛道目标带 [40%,50%]，AT-11）；对话推进率 ≥70% 参考（AT-19）；
5. **段落/句长/标点**——**统一按 `style-rules.md` 第十节「三遍 20 项自查清单」第一遍（段落结构）+ 第二遍（标点呼吸）过**，本文件不复述条目；本章只需额外记住三条硬线：`≤50 字段落占比 ≥60%`（AT-63）、`段 >100 字必修`、`半角标点 ≤10%`（AT-17）；
6. **环境必须参与叙事**——施压/预示/伏笔回收三选一，句句挂靠人物动作——禁纯景物描写空转；
7. **伏笔落地**——对照细纲伏笔规划表核对本章应回收已兑现、应新埋已落地——埋/收双标与表格编号一致（AT-22）；
8. **钩子与节末**——微钩 500 字/次、小钩 1500 字/次、中反转 3000 字/次（AT-27/28/29；埋设看目标、对标看实测带，两口径不互算）；章末断在冲突最高点、章末钩带类型后缀（新问题/新信息/情绪转折/危险升级）且连续两章不同类（AT-45）；卡点句（首锁章）落在"认知颠覆将破未破"瞬间、卡后 300 字内 ≥3 个钩子且卡后 200 字含 ≥1 个信息型反转（AT-18）；
9. **三件套与靶点**——`check-metrics.py --fragment` + `check-ai.py` + `check-length.py --fragment` 全 exit 0（或 ⚠️ 已人工确认）；本章靶点标注位已按细纲情绪靶点规划表落位。

## 二、全篇核验七项（末章写完逐项过，不过不进阶段 5）

**不带** `--fragment`，此时 AT-01 篇幅带 12000-16000 与章门 ❌ 生效：

1. **三件套整篇复跑**——`check-metrics.py` + `check-ai.py` + `check-length.py` 均**不带** `--fragment`（此时 AT-01 篇幅带 12000-16000 与章门 ❌ 生效）；
2. **产物链机检**——`check-artifacts.py <项目目录>`（节末钩字段/配角动机/伏笔双标对账/数字守恒/防狗血关键词/标注覆盖/靶点密度与节末钩）；
3. **双锚句 + 中卡点实测**——`check-length.py --paywall "锚句" --first-twist "锚句"`：反转须早于付费墙字位（AT-08），晚于即门不过；**中卡点须单独给锚句**：`check-length.py --midpoint "锚句"` 出中卡点字位，须落全文 45%-55%（AT-10，⚠️ 级）。⚠️ 首锁/首次反转双锚句只覆盖免费区、管不到中段——中卡点缺锚句即本项判**未核**（禁默认它已被双锚句覆盖）；偏离带即回阶段 3 重排中段节拍，不在正文层硬挪。卡后钩子口径：`check-length.py --paywall "锚句"` 出卡后钩子计数与三连击核对窗口（口径见 `workflow.md` 第四节）；
4. **伏笔回收率 ≥80%**——对伏笔规划表复点，未回收项不得悬空（AT-22，目标 100%）；
5. **钩子密度与节末钩轮换**——微钩/小钩/中反转实测落带（AT-27/28/29），连续两章不得同类型钩子（AT-45）；**免费区（导语至卡点）加密校验**（AT-80）：每 500 字 ≥1 个信息型钩子、卡点前 1000 字 ≥3 个——免费区平铺即等于把付费动机让给读者自己想象；
6. **信息投喂节奏**——前 1000 字新信息 ≥3 条、此后每 2000 字 ≥2 条、谜底落全文 70%-85%（AT-21）；
7. **标称即实测**——字数声称必须引用脚本实测输出，差 >10% 判门不过。

## 三、检查节奏

| 时点 | 跑什么 |
|---|---|
| 每章写完 | 自查九条（第 9 条跑三件套 `--fragment` 口径） |
| 每批末 | 单章门 + 三件套（`--fragment`）复跑本批末章 |
| 末章写完 | 全篇核验七项（不带 `--fragment`） |
| 进阶段 5 前 | `python3 ../../scripts/check-all.py <项目目录>` 一键全链（产物链对账 + 三件套 + 整篇字数/指标**禁 `--fragment`**） |

## 四、常见自查失败的定向修法

| 自查不过项 | 定向修法 |
|---|---|
| 章门字数不足 70% | 回细纲补节拍/场景，整章重写——禁注水式扩句（`rules.md` R1） |
| check-ai exit 2 | 按 `../shared/kill-ai.md` 四层清单改到 exit 0 |
| 伏笔回收率 <80% | 回阶段 3 对六表复点补埋/删埋 |
| 反转晚于付费墙 | 回阶段 3 重排付费点，不在正文层挪句子硬凑 |
| 段落细项不过 | 走 `../shared/style-rules.md` 第十节对应遍数，不在本文件重复建清单 |
| `check-all.py` 不可用 | 按上表逐条手工执行**同一标准**（`fullcheck` 的整篇口径 = 三件套不带 `--fragment`；目录模式的产物链对账 = 手工核对 `../../scripts/README.md` 的 A-M 项），标"⚠️ 人工核验（脚本降级）"——**降级不降门** |
