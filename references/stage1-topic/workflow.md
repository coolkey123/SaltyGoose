# 阶段 1 · 选题 — workflow（该干什么 + 该怎么做）

> **本文件回答：该干什么、该怎么做。** 验收线见同目录 `quality-gate.md`；自检手段见 `self-check.md`；禁令见 `rules.md`。
> 数值口径以 `../shared/authority-table.md`（AT-xx）为唯一权威。题材档案与命题决策链见 `../shared/genre-map.md`。

## 一、做什么

把模糊意愿变成 3 个可写候选，用数据化打分替用户排除"写出来没人看"的题。

**两条路线（第一件事就是判定走哪条）**：

| 路线 | 触发 | 扫榜 | 四指标表 | 候选卡热点依据卡 |
|---|---|---|---|---|
| **扫榜路线** | 用户未指定题材 | 必做 | 七平台逐行填 | 必填（挂对标平台/榜单） |
| **命题路线** | 用户带了明确想法 | **跳过** | **降为一行说明**（模板第 2 节标"命题路线，扫榜不适用"） | **仍必填**——见下 |

**为什么命题路线跳过扫榜却不能省热点依据卡**：九维评级的 S/A 判据要求"对标样本支撑"（第五节折算表），对标样本只能来自热点依据卡。省掉扫榜不等于没有对标物——用户自带的想法若指向某个在榜作品，那份对标就是依据；若确实无对标，按"无依据项评 C 并标待核"处置（`rules.md` 编造防线第 4 条），**不是把整张表划掉**。

## 二、扫榜选题法

**覆盖范围**：各大主流短篇平台逐一扫描——盐选（知乎/盐言/盐选同平台，**盐选唯一口径**，AT-26）/七猫/黑岩/点众/番茄小说（短故事频道）/豆瓣阅读（短篇）/微信读书（短篇/故事）；每个平台扫"近期热榜 + 新书榜 + 分类榜"三张榜。平台口径映射与采集纪律见 `../../assets/source-whitelist.md`。**新增三平台（番茄/豆瓣阅读/微信读书）特性数据无公开来源，采集项一律标"待核"**（编造防线同权）——扫榜实采补录并注明平台+采集日期；主战场仍是盐选，跨平台扫描只服务选题期市场调研，不改投稿口径。

**扫榜动作**：
1. **看情绪热度**——该平台近期什么情绪类型在榜（虐恋/反转/悬疑/治愈/打脸），比"题材名"更本质——题材会过气，情绪需求不会；
2. **看结构重复度**——同一结构（开局重生/复仇/换身份）是否刷屏；刷屏=风口也是红海，需差异化切口；
3. **看标题句式**——在榜标题的句式分布（第二人称质问/身份反差/时间数字/悬念省略），提炼当期有效句式；
4. **看评论区**——高赞评论在夸什么（"最后一段破防了"=情绪落点；"反转没想到"=结构有效），评论区是免费的爆款拆解报告。

**风口标注**：每个候选标 🔥爆发（同结构多篇在榜且数据递增）/ ⚡起风（冒头但未饱和）/ ⚠️饱和（同结构密集、增量放缓）。

**搜索降级三档**（防"半可用"时各自发明口径）：
- **可用**：实时扫榜+搜索指数可用 → 热度四指标逐项采集；
- **半可用**：仅部分平台可达或指数不可用 → 可证实项照采，不可证实项标"待核"，热度结论降级为"样本库口径+定性风口"；
- **不可用**：搜索完全不可用 → 停扫榜，用样本库（1514 篇语料口径）+ 用户采集卡，产物显式声明"⚠️ 无实时热度来源"。

## 三、热度四指标（选题报告固定表格字段）

`00-选题评估.md` 必须包含热度四指标表（AT-68），逐指标注明平台+采集日期：

| 指标 | 采集口径 | 无来源处置 |
|---|---|---|
| ① 同赛道近 30 天爆款数 | 平台榜单可数 | 标"待核" |
| ② 新增稿件数 | 平台新书榜可数 | 标"待核" |
| ③ 搜索指数 | 指数工具/平台搜索页 | 标"待核" |
| ④ 竞品密度 | 爆款数÷新增数，或红海-蓝海档位 | 标"待核" |

**竞品密度双口径（AT-68，定性定义，不设数值阈值）**：公开平台不提供统一分档线，禁编造数值阈值——两口径均可证实才写，不互算、报告双写：

- **口径甲（比值）**：竞品密度 = 同赛道近 30 天爆款数 ÷ 新增稿件数。仅当两项**均有来源**时才计算并写出算式；任一分母无来源，该比值整体标"待核"，禁用估算值填空；
- **口径乙（档位）**：红海-蓝海档位——按"同结构作品在榜密集度 + 增量趋势"定性分档（红海 = 同结构密集且增量放缓；蓝海 = 有需求缺供给）。档位判断须附一句依据（如在榜同结构篇数、风口标注），**无依据时标"待核"**；
- 两口径都无来源时，竞品密度列标"待核"，热度结论按下方纪律降级——**禁止给无来源定量密度断言**（编造防线同权）。

**纪律**：四指标**全缺**时热度判断降级为"样本库口径+定性风口"，**禁止给无来源定量热度断言**（编造防线同权——凡无来源一律标"待核"，禁以肯定语气写入）。

**征文活动信号（AT-75，四指标之外单列一行）**：`00-选题评估.md` 固定增列"征文活动信号"行——平台当期征文公告信号（主题/字数带/截止时间/奖金/与本题材的匹配度）。公告以平台当期公示为准，无来源标"待核"；命中征文赛道时**公告口径优先于本技能缺省口径**（含男频短篇征文 8000-29999 字通道——男频向题材卡仅经该通道启用，见 genre-cards README 第四条；红线判据不因通道放行）。

## 四、候选卡（每候选一张，三张整批产出）

```
候选卡 N：
- 题目/一句话概念（≤50 字硬上限、≤30 字更佳——AT-42；须过一句话验证三关：悬念+反常+画面）
- 赛道与情绪类型：
- 热度四指标摘要（爆款数__/新增数__/指数__/竞品密度__，注明平台+日期）
- 风口标注：🔥/⚡/⚠️
- 核心冲突一句话：
- 付费触点预设（读者为什么付费读完）：
- 差异化切口（与在榜同结构作品的差异）：
- 空白度搜索结果（四维同型篇数：核心设定__/主角身份__/反转__/意象__ → 档位 萌芽|黄金|挤压|红海；口径见 `../shared/genre-map.md` 4.1-2）
- 三维打分：需求热度__/10 ｜ 付费完读可行性__/10 ｜ 冲突自带性__/10 ｜ 总分__/30
```

**一句话验证三关**（缺一即候选不成立，不要指望用写作技巧拯救）：①**有悬念**（听完想知道结果）②**有反常**（违反日常认知）③**有画面**（能在脑中成像）。

**空白度搜索**（质量门 5b，红海即门不过）：四维各搜同型作品数，按 `../shared/genre-map.md` 4.1-2 口径计数（四维中 ≥2 维重合算同型、近 90 天窗口、红海取最严）。档位 **0-2 萌芽 / 3-8 黄金 / 9-20 挤压 / >20 红海**。红海先走创新偏移四法（换身份/换关系/换代价/换视角）救活并重验，四法用尽仍红海即弃题——**这一步与结构指纹（第六维）是两道不同的防撞闸**：指纹防"自己连着几篇同模式"，空白度防"跟全市场同模式"。

## 五、双打分（两套同名不同表，分别计分，取更严者）

**选题侧三维**（AT-31）：需求热度 / 付费完读可行性 / 冲突自带性，各 0-10，**总分 ≥25/30** 才够动笔线。

**命题侧九维**（AT-32，命题决策链必走非可选）：认知锚点三问 → 空白度搜索 → 九维评分——编辑喜欢（制度关联/开篇场景/天然节奏）× 读者爱死（代入/累积/疼位）× 创新爆棚（首次使用/结构创新/反转独特），各维 S/A/B/C 评级折算 10 分制，**均分 ≥8/10**，且综合 ≥2 个 A 级才通过。

**S/A/B/C 折算表（评级 → 10 分制）**：

| 评级 | 折算分 | 判据 | 可验证动作（必填，否则只能评 B/C） |
|---|---|---|---|
| S | 10 | 在榜同结构作品中的顶级配置，且本品有把握复刻 | 须点名 ≥2 本对标作品名 + 指出本品在哪一维**超出**它们 |
| A | 9 | 明确强于常见水平 | 须点名 ≥1 本对标作品名 + 一句「本品在〈某维〉更强，因为〈具体差异〉」 |
| B | 7 | 常见水平（赛道标配） | 无需对标——这是无证据时的缺省档 |
| C | 4 | 弱于常见水平，或无来源/无对标支撑 | — |

**"对标样本"的最小形态**（免去"要读多少"的内耗）：可以是作品名 + 一句可比维度结论，不必是完整拆解报告。命题路线下用户自带的对标同样算；若确无任何对标，**按 B/C 处置并在报告标"待核"，不得凭印象给 A/S**。

**折算纪律**：①评级须有上表的"可验证动作"（对标样本 + 具体差异），无依据项评 B 或 C 并在报告标"待核"——**禁无证据评 S/A**（编造防线同权）；②均分 = 九维折算分合计 ÷ 9；③"≥2 个 A 级"按评级计数，禁用折算分凑均分冒充 A 级；④九维与选题侧三维两套分别计分，取更严者。

**裁决规则**：两套打分**分别填写、分别计分、禁止混填**；任一套不过 = 候选不过；全军覆没则换思路重新出题（**一轮 = 3 个候选整批重出**），最多两轮（AT-51），仍不过如实告知用户请其定夺。

## 六、产物与确认门

**产物**：`00-选题评估.md`（热度四指标表 + 三张候选卡 + 双打分表 + 推荐结论）；`08-结构指纹.md`（六维指纹卡——叙事起点/主角行动模式/核心反转类型/核心意象类别/关系翻转方向/付费卡点触发情境，`check-fingerprint.py` 跨篇比对防同质化；新篇选题前先查指纹台账，连续 3 篇同模式触 AT-46 红线）。

**确认门①**：用户选定题目后进阶段 2。方式①全自动 = 快照自检点（产物照常落盘+一行摘要，不停留）；方式②逐阶段确认 = 等用户拍板。
