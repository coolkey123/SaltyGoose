# 阶段 1 · 选题 — rules（必须遵守什么）

> **本文件回答：必须遵守什么（本阶段特有规范 + 禁令）。** 跨阶段规范按归属判定树分流：产物格式 → `../../templates/`；术语 → `../../assets/glossary.md`；平台/来源事实 → `../shared/authority-table.md` 与 `../../assets/source-whitelist.md`。
> 红线判据唯一正本 = `../../assets/compliance-redlines.md`（本文件只留执行规程）。

## 一、编造防线（本阶段落地）

1. 凡无来源的热度/数据/榜单信息一律标"**待核**"，**禁以肯定语气写入**；
2. **禁止给无来源定量热度断言**（四指标全缺时降级为"样本库口径+定性风口"）；
3. **禁止给无来源定量密度断言**（竞品密度双口径，两口径都无来源即标"待核"）；
4. **禁无证据评 S/A**——九维评级缺"可验证动作"（S 需点名 ≥2 本对标 + 超出维度；A 需点名 ≥1 本对标 + 具体差异句；见 `workflow.md` 第五节折算表）的，一律评 B/C 并标"待核"。对标样本的最小形态 = 作品名 + 一句可比维度结论，不要求完整拆解报告。

## 二、红线处置纪律

1. **红线命中 = 拒绝 + 替代**：拒绝话术之外**必须给替代方向**（同情绪合法替代题材或结构改造方案，如"催泪亲情"改"亲情+反击"），**禁只拒绝不给路**；
2. 判据查 `../../assets/compliance-redlines.md`（18 项禁入清单 + 限流词三类 + 题材卡红线边界的唯一正本），本文件不复述判据；
3. **男频边界**：男频向题材仅经平台征文通道启用（AT-75：公告口径优先），**红线判据不因通道放行**——后宫向/物化女性/无代价碾压视角禁入；
4. 连续 3 篇不得用同一故事模式（指纹同质化，AT-46）。

## 三、口径纪律

1. **盐选唯一口径**（AT-26）：跨平台扫描只服务选题期市场调研，不改投稿口径；
2. **路线与字段的绑定**：命题路线免扫榜、免第 2 节七行表，但**候选卡的热点依据卡不免**——它供九维 S/A 评级的对标判据（`workflow.md` 第五节）；无对标即评 C + 标"待核"，不是免填；
3. 征文公告口径与技能缺省口径冲突时，**公告口径优先**（AT-75）；
4. 搜索降级三档（可用/半可用/不可用）各自处置，**禁"半可用"时发明口径**；
5. 两套打分（选题三维/命题九维）**分别填写、分别计分、禁止混填**，取更严者。

## 四、空白度纪律

1. 四维（核心设定/主角身份/反转/意象）**逐一搜**，禁只搜一维下结论；计数口径按 `../shared/genre-map.md` 4.1-2；
2. **红海即门不过**（质量门 5b）——先走创新偏移四法（换身份/换关系/换代价/换视角）并重验，四法用尽仍红海即弃题；
3. 判为挤压档须写实「差异化切口」字段才可过线；
4. **空白度 ≠ 结构指纹**：空白度防"跟全市场同模式"，指纹防"自己连着几篇同模式"，两道闸并行不互相替代。

## 五、产物纪律

1. 四指标表、候选卡、双打分表为 `00-选题评估.md` 固定字段，缺一即门不过；
2. 候选卡须挂输入锚点回应（或偏离声明+理由），禁凭空出题不回应输入；
3. 整批重出最多两轮（AT-51），禁无上限震荡；仍不过交用户定夺。
