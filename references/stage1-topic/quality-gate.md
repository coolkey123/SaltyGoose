# 阶段 1 · 选题 — quality-gate（该做到哪一步）

> **本文件回答：该做到哪一步。** 怎么做见同目录 `workflow.md`；自检手段见 `self-check.md`；禁令见 `rules.md`。
> 数值口径以 `../shared/authority-table.md`（AT-xx）为唯一权威。七阶段门总览见 `../README.md`。

## 阶段 1 质量门（全过才进确认门①）

| # | 门条件 | 口径 |
|---|---|---|
| 1 | 热度四指标入表 | AT-68；四指标为 `00-选题评估.md` 固定表格字段，逐指标注明平台+采集日期；无来源项标"待核" |
| 2 | 三维打分 ≥25 | AT-31：需求热度/付费完读可行性/冲突自带性各 0-10，总分 ≥25/30 |
| 3 | 九维均分 ≥8 | AT-32：命题侧九维均分 ≥8/10 且综合 ≥2 个 A 级；S/A 须带「可验证动作」（对标样本 + 具体差异，见 workflow 第五节折算表），无依据只能评 B/C |
| 4 | 双打分取更严 | 两套分别计分，任一套不过 = 候选不过 |
| 5 | 一句话验证三关全过 | 悬念 + 反常 + 画面，缺一即候选不成立 |
| 5b | **空白度已搜且非红海** | 四维搜同型作品数（核心设定/主角身份/反转/意象），计数口径见 `../shared/genre-map.md` 4.1-2；档位 0-2 萌芽 / 3-8 黄金 / 9-20 挤压 / >20 红海；**红海即门不过**（回第三节创新偏移四法：换身份/换关系/换代价/换视角，偏移后重验）；挤压档须写明差异化切口才可过 |
| 6 | 征文活动信号单列 | AT-75：四指标之外固定一行，公告口径优先、无来源标"待核" |
| 7 | 红线零命中 | 18 项禁入清单逐项过（判据唯一正本 = `../../assets/compliance-redlines.md`） |
| 8 | 限流词零命中 | 三类可证实类别排查（敏感实体/违规行为/平台当期公告点名） |
| 9 | 候选挂输入锚点+热点依据 | 每候选须挂用户输入锚点回应（或偏离声明+理由）与热点依据卡（来源或"待核"）。**用户输入为空的三态处置**：用户只给方向词（如「帮我写个盐选故事」）时锚点无处可挂——此时须在候选卡明示「⚠️ 用户输入为空，无锚点可挂」并按 `SKILL.md` 第四节输入规范列出待补项，**禁捏造锚点凑门、禁静默跳过本门**子 agent 实测发现该态在原规则下无法执行，照实说明会被判门不过 |
| 10 | 结构指纹已登记 | `08-结构指纹.md` 六维填全，`check-fingerprint.py` 同型比对（exit 0 或预警已处置） |

## 不过的处置

- **整批重出**：全军覆没 = 一轮整批重出 3 个候选，最多两轮（AT-51），仍不过如实告知用户请其定夺，禁止无上限震荡；
- **空白度红海**：按 `../shared/genre-map.md` 4.1-3「创新偏移四法」（换身份/换关系/换代价/换视角）救活，偏移后**重验空白度 + 赛道可识别 + 热梗三关**；四法用尽仍红海 = 弃题换候选，不许硬写；
- **红线命中**：拒绝 + 替代（处置细则见 `rules.md` 与 `../../assets/compliance-redlines.md`）；
- **同型预警**：指纹 ≥2 维同值 → 换 ≥2 个维度重出；连续 3 篇同模式触 AT-46 红线。

## 确认门①

门全过 + 用户选定题目 → 进阶段 2。方式①全自动 = 快照自检点；方式②逐阶段确认 = 等用户拍板。拍板前发现关键设定缺失或事实无来源 → 判"需补信息"先追问，不许带病放行。
