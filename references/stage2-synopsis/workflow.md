# 阶段 2 · 梗概 — workflow（该干什么 + 该怎么做）

> **本文件回答：该干什么、该怎么做。** 验收线见同目录 `quality-gate.md`；自检手段见 `self-check.md`；禁令见 `rules.md`。
> 数值口径以 `../shared/authority-table.md`（AT-xx）为唯一权威。一句话法则见 `../shared/principles.md`；题材正文档案按 aliases 路由单卡（`../../assets/genre-cards/<题材卡>.md`，路由表见 `../shared/genre-map.md` 第十四节）。

## 一、做什么

把阶段 1 选中的题压成"一根能撑起全文的杠杆"——**一句话梗概 + 情绪弧线 + 核心反转**，产出梗概卡九字段。梗概是细纲的输入：梗概立不住，细纲必塌。

## 二、梗概卡九字段（缺一即门不过）

> **字段正本 = `../../templates/01-synopsis.md`**，本节只讲各字段的做法与判据，字段名/顺序/要求以模板为准（两处必须同序同名，`check-consistency.py` 断言锁死）。

```
1. 一句话梗概（双版本：20 字极简 + 100 字扩展；≤50 字讲清主线、含冲突或悬念词，AT-42）
2. 目标读者与情绪承诺（写给谁、承诺什么情绪、落地在哪）
3. 核心冲突（谁 vs 谁、争什么、为什么不能退让）
4. 悬念三要素（利害关联 / 时空压迫 / 信息黑洞）
5. 情绪弧线任务清单（六节点交流电曲线 + 主疼位指认行 AT-73 + 三项量化：靶点总数 AT-33 / 击穿级 / 压迫递进四层 AT-81）
6. 双峰反转 + 分级（第一峰 50-60% 真相第一层 / 终局峰 80-95%，各标 3 处埋伏笔位；铁律三条）
7. 核心意象（1 个信物，首尾闭环，≥3 次递进，闭环四选一）
8. 主角弧光一句话（A 点错误信念 → B 点新认知 + 转折点）
9. 结局走向与暂定标题（HE/BE/开放/双结局 + 一句结局画面；标题三档 AT-24 + 核心词前 3000 字兑现 AT-65）
```

**字段 2「情绪承诺落地在哪」**：承诺须指到承载它的字段（通常指字段 5 的主疼位兑现段），否则承诺悬空——阶段 6 审稿核"情绪配方与主疼位一致"时无锚可对。

**字段 3「为什么不能退让」**：核心冲突必须写出**不可退让的理由**，否则读者不理解主角为何不和解、不报警、不放弃；只写"两人矛盾"等于没写冲突。

## 三、悬念三要素（缺一即概念不成立）

| 要素 | 含义 | 自检问句 |
|---|---|---|
| 利害关联 | 主角输不起 | "如果主角失败了，会失去什么不可替代的？" |
| 时空压迫 | 等不起 | "为什么必须现在解决？拖下去会怎样？" |
| 信息黑洞 | 想不通 | "读者最想知道答案的那个问题是什么？" |

## 四、情绪弧线（交流电，禁直流电）

好故事的情感曲线像**交流电**：紧张 → 松弛 → 更紧张 → 更松弛 → 终极紧张 → 彻底释放。纯催泪故事是**直流电**（只有一个方向）→ 推荐流表现极差。

**弧线节点表**（梗概卡字段 5 必填）：

| 节点 | 位置 | 内容 |
|---|---|---|
| 起 | 0-10% | 稳态中的裂缝（前 300 字抛核心矛盾） |
| 第一峰前缓冲 | 35-45% | 松弛段（也要有信息量，禁空转） |
| 第一峰 | 50-60% | 真相第一层（双峰反转之一） |
| 中段蓄力 | 60-80% | 更糟的境地 + 情绪对冲（爽点后立刻植虐点） |
| 终局峰 | 80-95% | 终局反转 |
| 释放 | 95-100% | 彻底释放 + 余韵留白（尾声 50-500 字） |

**情绪锚点法**：爆款从不写情绪名称，只写一个可触摸的物——❌"我很绝望" → ✅"那只蜂蜜水还放在桌上，盖子没拧紧"。一个情绪只配一个锚点；锚点至少复现 1 次（第二次出现时意义已变）。

### 主疼位指认（梗概卡字段 5 内指认行，AT-73）

**主疼位 = 读者追更的情绪燃料**——全文只烧一种主疼，烧两种以上=情绪失焦。五型指认 **1 个主疼位**（可叠加辅位，但主疼位唯一）：

| 疼位 | 读者追的是什么 | 典型兑现 |
|---|---|---|
| 被辜负 | "他/她必须付出代价" | 复仇/清算落地 |
| 被误解 | "真相必须大白" | 公开审判式打脸 |
| 求而不得 | "差一点就在一起" | 错位戳破/双向奔赴 |
| 身份落差 | "他/她必须被看见" | 身份揭晓/众人改口 |
| 丧失 | "失去了才懂得" | 追悔/遗物揭秘 |

**指认纪律**：①主疼位从题材卡的"常见情绪转化"与细纲前先对一遍——`genre-cards/` 路由表给"主疼位初值"，**初值只作路由，本字段指认为准**；②主疼位决定靶点布局重心（AT-33 前中后配额向主疼位的兑现段倾斜）；③阶段 6 审稿核"情绪配方与主疼位一致"——跑题的情绪峰值（主疼位是被辜负，中段大段甜宠发糖）判结构问题；④命题侧九维"读者爱死（代入/累积/疼位）"评分按本字段值评，禁凭感觉。

## 五、双峰反转（各标 3 处可埋伏笔位置）

**第一峰（50-60%）**：真相第一层——读者发现"之前的理解是错的"（发现深度之中层级："没想到"）。
**终局峰（80-95%）**：认知框架翻转——读者发现"整个认知框架是错的"（"细思极恐"）；极深层级=读者发现自己也是被操纵的一部分。

**反转铁律**（三条缺一即反转无效）：
1. **回看 ≥3 处暗示**——反转成立前文须有 ≥3 处可回看的暗示（梗概卡字段 6 逐处标出）；
2. **不引入前文没出现的信息**——反转的燃料必须来自已埋伏笔，禁临时发明；
3. **叙述者可隐瞒不可说谎**——叙述者隐瞒=合法伏笔，说谎=违规（联动审稿八查第 2 查）。

## 六、产物与确认门

**产物**：`01-梗概.md`（梗概卡九字段）。

**确认门②**：用户拍板梗概后进阶段 3。方式①全自动 = 快照自检点；方式②逐阶段确认 = 等用户拍板。拍板前发现关键设定缺失或事实无来源 → 判"需补信息"先追问，不许带病放行。
