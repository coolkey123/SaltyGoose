# 阶段 2 · 梗概 — quality-gate（该做到哪一步）

> **本文件回答：该做到哪一步。** 怎么做见同目录 `workflow.md`；自检手段见 `self-check.md`；禁令见 `rules.md`。
> 数值口径以 `../shared/authority-table.md`（AT-xx）为唯一权威。七阶段门总览见 `../README.md`。

## 阶段 2 质量门（全过才进确认门②，无脚本，清单门）

| # | 门条件 | 口径 |
|---|---|---|
| 1 | 梗概卡九字段齐 | 缺一即门不过（字段正本 = `../../templates/01-synopsis.md`，workflow 第二节讲做法与判据；由八扩为九，补入「目标读者与情绪承诺」与「核心冲突」——二者原有门条目在管却不在字段清单里） |
| 2 | 一句话梗概双版本齐 | 20 字极简版 + 100 字扩展版；≤50 字讲清主线、能勾出"然后呢"、含冲突或悬念词（AT-42） |
| 3 | 悬念三要素齐 | 利害关联 + 时空压迫 + 信息黑洞 |
| 4 | 单线推进声明 | 70% 单线推进 + 一个核心支点，禁多线摊薄 |
| 5 | 双峰反转各标 3 处伏笔位 + 反转分级 | AT-09（50-60% 第一峰 / 80-95% 终局峰）；分级 A 级 ≥1 + B/C 级 2-4 |
| 6 | 反转铁律三条全过 | 回看 ≥3 暗示 / 不引入前文没有的信息 / 叙述者不可以说谎 |
| 7 | 情绪弧线节点表六节点齐 | 禁直流电；**情绪任务清单三项量化**：靶点总数（AT-33，按 AT-01 篇幅带折算 18-24 个、虐文 22-29）/ 击穿级数量（虐文 ≥2 六星，其余 ≥1）/ 压迫递进四层（AT-81，单层 3000-4000 字、须递增非并列） |
| 8 | 主疼位指认行齐 | AT-73 五型指认 1 个主疼位（辅位可叠加、主位唯一） |
| 9 | 核心意象闭环 + 弧光一句话 | 1 个信物首尾闭环、≥3 次递进（禁多物堆砌）；A 点错误信念 → B 点新认知 + 转折点在哪，一句话可答 |
| 10 | **暂定标题合规 + 兑现预演（同属字段 9，合并）** | 字数三档 ≤15 最佳 / 16-20 合格 / >20 硬门未过（AT-24）；不剧透；禁问号感叹号；**核心词须能在正文前 3000 字兑现（AT-65），写梗概时就预演并标注兑现位** |
| 11 | **情绪承诺有落地字段** | 字段 2 的情绪承诺须指到承载它的字段（通常为字段 5 主疼位的兑现段），并写明不可退让理由（字段 3）——禁承诺悬空、禁空泛读者画像 |

## 不过的处置

缺字段 → 补齐再进；三要素/铁律不过 → 回概念层重排（不是文字润色）；拍板前发现关键设定缺失或事实无来源 → 判"需补信息"先追问，不许带病放行。

## 确认门②

门全过 + 用户拍板梗概 → 进阶段 3。方式①全自动 = 快照自检点；方式②逐阶段确认 = 等用户拍板。
