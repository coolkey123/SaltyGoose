# 阶段 3 · 细纲 — rules（必须遵守什么）

> **本文件回答：必须遵守什么（本阶段特有规范 + 禁令）。** 跨阶段规范按归属判定树分流：产物格式 → `../../templates/02-outline.md`；术语 → `../../assets/glossary.md`；防狗血判据 → `../../assets/compliance-redlines.md` 与 `../shared/genre-map.md`。

## 一、结构纪律

1. **`02-细纲.md` 单文件两篇，禁拆回两个文件**（脚本双视图同指本文件，拆开即对账失效）；
2. **卡点跟字位走，不跟章号走**（AT-41）；禁压 3000 前、禁拖 4000 后；
3. **保后段章 1800 底线优先**——加厚回排时后段章跌破 1800 即 AT-02 越界；
4. 回排无空间时**停下如实汇报三选一**（加厚前两章/保后段章幅/压总字数），交用户裁决——**禁静默砍导语或尾声凑数，禁让任一章跌破章门硬凑**；
5. 字数预算列**禁写"约/左右"、禁留空**——必须逐章填具体数字；
6. **连续两章不得同类型钩子**（AT-45 同质化红线）；
7. 章题每章含情绪动词或强动作动词，**禁中性描述题**；章题不剧透核心反转。

## 二、伏笔纪律

1. 伏笔 **≥3 个**，回收率 **≥80%**（AT-22，目标 100%）；
2. 每个伏笔必须有指定回收章，**未回收项禁止悬空**；
3. 落差时长 ≤3000 字（AT-44）；
4. 梗概卡字段 6 的 3+3 处埋伏笔位**必须全部落入伏笔规划表**。

## 三、人设纪律（配角五规矩，三查同轴）

1. 每个有台词的配角须有独立动机——缺动机=工具人，门不过；
2. 配角不得为推进冲突集体失智/降智；
3. 配角不得为成全主角而降智——主角胜利须靠自己，非靠对手变蠢；
4. 反派/偏心家人须有可理解动机，非纯坏脸谱；
5. 配角意象 ≤2 个，不喧宾夺主。

## 四、加载与收口纪律

1. **禁 32 张题材卡全量同载**——按 aliases 路由单卡；未命中走"最近卡+差异标注"（细纲注明借用哪张卡的哪些打法）；
2. **medium 置信度题材卡须在细纲备注"⚠️ 题材卡置信度 medium"**（可用样本量较弱，打法仅作方向参考）；
3. 防狗血零命中——婚恋/都市职场/悬疑/家庭等负面清单阶段 3 查一次、阶段 6 复查一次（判据见 genre-map 与 compliance-redlines）；
4. 对标差异化必须明确——禁照搬在榜同结构作品；
5. **细纲不过关不动笔**——确认门③未过，禁提前写正文。
