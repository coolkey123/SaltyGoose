# 题材提示卡库（genre-cards/）

> 32 张题材正文提示卡，供七步法**阶段 2（梗概）/ 阶段 3（细纲）/ 阶段 4（写作）**按需加载——题材定了再加载对应的那一张，**禁 32 张全量同载**（Reference Gate 同款纪律：单会话段只带"当前题材一张卡 + 当前阶段规则"）。

## 一、这是什么

每张卡是一个题材的**正文提示档案**：开场抓手、冲突发动机、爽点与情绪释放、对话声线、章尾钩子、场景颗粒、前中后期打法、节奏密度、本章取舍、禁止漂移。卡不决定"写什么故事"（那由阶段 1 选题 + 阶段 2 梗概决定），卡决定"这个题材的正文怎么写才像这个题材"。

**来源**：`local_longform_sample_derived`——由本地同题材长篇样本派生（frontmatter `source` 字段）。每卡抽样 24 本 × 前/中/后节段 24/24/24，共 72 个节段样本（各卡"证据摘要"节列明可用样本量）。**样本是长篇，产物是短篇**——卡内打法按短篇容积折算使用（章数折算见 AT-50），禁把长篇节奏直接搬进 12000-16000 字短篇。

**置信度**（frontmatter `confidence`）：**23 张 high + 9 张 medium**（medium：东方仙侠/历史脑洞/快穿/悬疑脑洞/民国言情/游戏体育/现言脑洞/西方奇幻/青春甜宠——可用样本量 54-308 本，信号较弱）。使用 medium 卡时在阶段 3 细纲备注"⚠️ 题材卡置信度 medium"，其打法与前中后节奏仅作方向参考，以本书设定与同题材对标优先。

## 二、平台口径收口（重要）

卡内可用数据仅为**题材参考**，平台硬门一律回到 `../../references/shared/authority-table.md`（AT-26 盐选唯一口径）：

| 卡内说法 | 本技能口径 |
|---|---|
| "平台硬门以 ../../references/shared/authority-table.md 为准" | 平台硬门一律以 `../../references/shared/authority-table.md`（AT-xx）为准——字数带/付费墙字位/对话占比带/段落纪律等以 AT 表为唯一权威 |
| "段落/对话数据仅作题材参考" | 同义——卡内段落中位、对话占比是**长篇样本的题材参考值**，不是本技能机检口径；机检判罚以 AT 表与脚本为准（如 AT-11 对话占比带、AT-63 段落合规率） |

卡内一切数值（段落中位约 23-31 字、对话占比 19-35% 等）均为**长篇样本参考值，非平台硬门**——引用时随卡标注"长篇样本参考"，禁当机检阈值使用。

## 三、路由与使用纪律

1. **按 aliases 路由单卡**：选题/梗概确定题材后，用题材名与卡的 `aliases` 匹配（含别名，如"霸总/先婚后爱"→ `豪门总裁.md`），**一次只加载命中的那一张**；路由表见 `genre-map.md` 第十四节（卡 × 八赛道 × 主疼位初值）。
2. **禁全量加载**：32 张同载 = 上下文灾难且违反 Reference Gate；未命中路由表的题材，走"最近卡 + 差异标注"（在细纲注明借用了哪张卡的哪些打法、哪些不适用）。
3. **卡与赛道正交**：卡 = 题材类型（决定设定库与读者预期），八赛道 = 情绪配方（决定情绪弧线与靶点配额，见 `genre-map.md` 第三节）——两者组合使用，禁用卡替代赛道弧线。
4. **红线边界（命中即禁，无替代不放行）**：
   - **双男主卡**：aliases 含 BL/耽美——**耽美向禁入**（红线，`../../references/stage1-topic/rules.md` 红线节）；只写去标签化双男主纯爱亦须过未成年恋判据（恋爱线双方 ≥18 岁）；
   - **男频向卡**（战神赘婿/传统玄幻/玄幻脑洞/都市高武/游戏体育/抗战谍战/科幻末世/西方奇幻/都市修真）：⚠️ 盐选主池为女频主场，此类卡**仅在用户明确走男频征文通道时启用**（征文口径以当期公告为准，见 AT-75），且"男频视角"红线判据不因通道放行——禁后宫向/物化女性/无代价碾压视角。
5. **卡不覆盖平台事实**：卡的平台字段统一"盐选短篇"，但不含投稿规则/分成/审稿周期——那些一律查 `../../references/shared/authority-table.md` 与 `../../references/stage7-delivery/workflow.md`。

## 四、卡结构（15 节，32 张统一）

正文提示词 / 主线目标 / 开场抓手 / 冲突发动机 / 爽点与情绪释放 / 常见情绪转化 / 对话与声线 / 章尾钩子 / 场景颗粒 / 正文落点 / 前中后期打法 / 节奏密度 / 本章取舍 / 禁止漂移 / 证据摘要。

消费时机：阶段 2 读"主线目标/常见情绪转化"定情绪弧线方向；阶段 3 读"冲突发动机/前中后期打法/章尾钩子"排节拍与钩子轮换；阶段 4 每章前读"开场抓手/对话与声线/场景颗粒/本章取舍/禁止漂移"。
