# 来源白名单与证据纪律（source-whitelist.md）

> **本文件是全库"外部事实怎么引"的唯一正本**——平台事实、热度数据、征文信息、相似度与平台规则核验的来源分级与标注纪律。
> 核心原则：**无来源 = 标"待核"，禁猜测代填（编造防线）**。本表管"什么来源算数、怎么标"；不管口径数值（那是 AT 表）。

## 一、平台事实（唯一来源 = 平台当期公示）

| 事实类 | 唯一来源 | 标注纪律 |
|---|---|---|
| 字数带/标题/导语/章数要求 | 平台当期公示 | 检索不到当期公示时按本技能缺省口径交付，备注"⚠️ 平台当期规则未核（无公开来源）"；**禁把无来源的"当期规则"当改稿依据** |
| 征文活动（主题/字数带/截止/奖金） | 平台当期征文公告（AT-75） | 公告口径优先于缺省口径；无来源标"待核" |
| 付费墙分隔符/AI 辅助创作声明 | 平台当期公示 | 条件项：联网可核才核；做不到标"⚠️ 未核+原因" |
| 分成/审稿周期/推荐机制 | 平台公示 | 卡内不覆盖平台事实——一律查平台口径（genre-cards 纪律） |

## 二、热度数据（扫榜四指标）

| 数据类 | 固定列 | 标注纪律 |
|---|---|---|
| 近 30 天爆款数 / 新增稿件数 / 搜索指数 / 竞品密度 | 平台 × 四指标（盐选/七猫/黑岩/点众/番茄短故事/豆瓣短篇/微信读书） | 每格带来源（链接+采集日期）；**无来源标"待核"** |
| 搜索指数不可得 | — | 按降级三档处置（可用/半可用/不可用），禁发明标准 |
| 新增三平台特性数据 | — | 无公开来源，采集项同权标"待核" |

## 三、证据分级（全库通用）

| 级别 | 含义 | 用法 |
|---|---|---|
| **平台当期公示** | 官方公告/规则页 | 平台事实唯一准源；与缺省口径冲突时**以平台为准**修订 |
| **公告口径** | 征文/活动公告 | 命中征文赛道时优先于缺省口径（AT-75） |
| **多源实操指南** | 多个独立第三方指南互相印证 | 可作缺省形态参考（如付费墙分隔符形态），引用时标"多源印证，当期规则待核" |
| **作者手写样例** | tests/golden 与 assets/exemplars | 文风与盲测对照；**不证明市场结果** |
| **本地样本派生** | genre-cards 的 local_longform_sample_derived | 题材打法参考（长篇样本值，非平台硬门）；禁当机检阈值 |
| **无来源** | 查不到 | 标"待核"/"⚠️ 无来源"；禁猜测代填、禁凭印象断言 |

## 四、引用纪律（四条）

1. **每个外部数字必须带来源**——链接+采集日期；不可复现的数字不许写进产物；
2. **无来源不填空**——字段空缺填"待核"或"⚠️ 无来源"，禁留空格、禁猜测代填（编造防线）；
3. **平台事实冲突裁决**：当期公示 > 公告口径 > 多源实操 > 缺省口径；技能缺省口径只在无当期来源时生效；
4. **红线类事实不替平台表态**——审稿报告只提示待核，不判死（口径见 `../references/stage6-review/rules.md`）。
