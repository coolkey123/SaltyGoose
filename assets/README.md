# assets/ — 长期资产（被反复引用的资料，不是流程规则）

> **本目录是什么**：写作过程中反复加载的资产——题材卡库、范文库、术语表、来源白名单、红线正本、执行提示词。
> 与 `../references/` 的分界：references 管"流程怎么走"（七阶段规则），assets 管"手里有什么资料可用"。
> Reference Gate 纪律同样适用：单会话段只带"当前需要的那一份"，禁全量同载。

## 资产清单

| 资产 | 文件 | 唯一性 |
|---|---|---|
| 题材提示卡库 | `genre-cards/`（32 卡 + README，按 aliases 路由单卡） | 卡内打法唯一正本；平台硬门一律回 AT 表 |
| 范文库 | `exemplars/`（good/ 回归复制 + bad/ 反例） | 回归正本在 `../tests/golden/`；同文断言盯双份 |
| 术语表 | `glossary.md` | **全库术语唯一定义处**；数值不在本表（去 AT 表） |
| 来源白名单 | `source-whitelist.md` | **外部事实引用纪律唯一正本** |
| 合规红线 | `compliance-redlines.md` | **红线判据唯一正本**（18 项禁入 + 限流三类 + 题材卡边界 + 相似度接线） |
| 执行提示词 | `prompts.md` | 每阶段一条五段式提示词 + 四道确认门摘要；与口径冲突时改提示词 |

## 三条铁律

1. **唯一正本不复制**：术语/来源纪律/红线判据在 assets 只存一份，他处只引不复制——发现第二份清单按本目录正本合并；
2. **exemplars 禁入全库扫描**：`bad/` 是故意的坏样例（AI 味违禁词集合），`check-consistency.py` 的 md_library 明确排除本目录；
3. **资产也要守 Reference Gate**：32 张题材卡禁全量同载，一次只加载命中的那一张 + 当前阶段规则。
