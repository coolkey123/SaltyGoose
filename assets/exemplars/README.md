# assets/exemplars/ — 范文库（盲测对照源）

> **本目录是什么**：正例/反例范文，供阶段 6 终审「盲测对比」与写作学习取用。
> **双轨纪律（D3 决策）**：回归测试正本在 `../../tests/golden/`（run-tests.py 路径依赖，原位不动）；本目录是资产视图的**复制**，供人直接阅读。改内容必须两端同步——`check-consistency.py` 有同文断言盯着，单边漂移即报错。

## 目录

| 目录 | 内容 | 用途 |
|---|---|---|
| `good/` | 5 篇 golden 文风样例（g10/g12/g14/g15/g16，作者手写、过机检片段口径）+ good-sample.md | 阶段 6 盲测对比内部标准样例；文风学习正例 |
| `bad/` | bad-sample.md（故意违规集合） | 反例示警：AI 味、虚词堆叠、同主语连段等问题长什么样 |

## 使用纪律

1. **盲测对比边界**：与 `good/` 混读判"哪个更想往下读"——A 组胜只证明"比内部标准样例更抓人"，**不证明能打赢当期榜上真作品**；无外部对照源时结论禁写"具备爆款相"（口径见 `../../references/stage6-review/workflow.md` 终审工序 4）；
2. **外部真爆款对照源自备**：涉及第三方版权，不随技能包分发（见 `../../tests/external/README.md`），缺位时盲测四维标"⚠️ 未与外部真作品对照"；
3. **bad/ 是故意的坏样例**——含大量 AI 味违禁词，全库扫描禁入本目录（`check-consistency.py` 的 md_library 明确排除），人也别当正例读；
4. golden 正本若更新（作者新写样例），必须同步复制进 `good/` 并保持同文。
