# 术语表（glossary.md）

> **本文件是全库术语的唯一正本**——同一概念只在这里定义一次，各处使用时不重新解释、只引用。
> 口径数值（阈值/字位/带）不在本表——数值唯一权威是 `../references/shared/authority-table.md`（AT-xx）。本表只管"这个词是什么意思"。
> 新增术语先进本表；发现两处对同一概念有不同表述时，以本表为准回改另一处。

## 一、流程与结构术语

| 术语 | 定义 |
|---|---|
| 七步法 / 七阶段 | 选题 → 梗概 → 细纲 → 写作 → 润色 → 初审与终审 → 交付，七个顺序阶段，每阶段四道确认门之一卡边界 |
| 确认门（四道） | ①选题定稿 ②梗概定稿 ③细纲定稿 ④成品交付；方式①自动交付可叫停、方式②用户点头后交付；记录模板 `../templates/gate-record.md` |
| 6a / 6b | 阶段 6 的两半：6a = 初审（机检数字报告 + 主观六维评分 + 根因路由，产 05-初审报告）；6b = 终审（七道工序放行，产 05-终审报告） |
| 产物链（00-08） | 00-选题评估/01-梗概/02-细纲/03-正文/04-标注稿+04-净稿/05-初审报告+05-终审报告/06-投稿包/07-复盘/08-结构指纹；外置记忆与断点续写的唯一依据 |
| 双版本 | 阶段 5 的标注稿与净稿；除标注符号外逐字一致，唯一允许差异 = 标注本身 |
| 双峰 | 50-60% 真相第一层 + 80-95% 终局反转两个情绪/反转峰位 |
| 黄金三章 | 前 3 章的硬门组合：第 1 章前 300 字抛核心矛盾、第 2 章标线索位、第 3 章首次打脸/反转 |
| 卡点 / 首锁 | 付费墙位置：止于"认知颠覆将破未破"瞬间；字位口径见 AT-04/05 |
| 续写锚点 | 批写断点时记在当批末尾的一行：下章钩位/钩型/伏笔待办 |

## 二、机检与质检术语

| 术语 | 定义 |
|---|---|
| 三件套 | `check-metrics.py` + `check-ai.py` + `check-length.py`；阶段 4 每章与全篇各跑一轮（`--fragment` 口径区分） |
| MSS | check-mss.py 的五模块机检评分（F 形式/B 标题导语梗概金句/T 结构位置/D 密度代理/R 回收兑现，权重 30/20/25/15/10） |
| 12 硬门 | MSS 的 12 项一票否决格式门，任一触发 → MSS 封顶 59；展开见 `../references/stage6-review/quality-gate.md` P0 |
| 18 维终审 | 6b 放行评分：六维审评分 6 + MSS 五模块折算 5 + 完读率三环 3 + 盲测四维 4；门值见 AT-62 |
| 75 项拒稿门 | 三级勾选表：P0 格式 12 项 / P1 内容 47 项 / P2 商业 16 项（AT-54；原 18 项删平台口径核验/相似度检测后为 16） |
| 复合式标注 | 机检唯一认的标注写法：`【爽点+打脸】`式七类 + `【伏笔·埋·Vx·描述】`；单类写法静默归零 |
| 靶点句 | 情绪峰值句 + 卡点句 + 金句 + 反转揭示句四类；送检口径 = 所在章整章过 check-ai（脚本全文级，无单句送检模式） |
| 标称即实测 | 任何字数/密度/回收率声称必须引用脚本实测输出，差 >10% 判门不过 |
| 冷启动纪律 | 审稿必须与写作过程隔离（独立 sub-agent/隔会话/隔 30 分钟+标注）；未隔离时 18 维门值收紧到 ≥8.8 |
| 条件项 | 联网可核才核、有工具才测的核验项：做不到标"⚠️ + 原因"，不计门、禁假合格。投稿面条件项（平台当期规则）按阶段 7 口径执行；初审/终审原设的平台口径核验/相似度检测两项 已删 |
| 降级三档 | 搜索不可用时的处置：可用/半可用/不可用；禁发明标准 |
| ⚠️ / ❌ 语义 | ⚠️ = 待修（exit 2，人工确认后可放行）；❌ = 必修（exit 3） |
| 结构指纹 | 六维封闭枚举（叙事起点/主角行动模式/核心反转类型/核心意象类别/关系翻转方向/付费卡点触发情境）；防跨篇同质化的比对单元 |
| 同型预警 | 任两篇指纹 ≥2 维同值；连续 3 篇同模式触 AT-46 红线 |

## 三、情绪与写作术语

| 术语 | 定义 |
|---|---|
| 主疼位 | AT-73 五型（被辜负/被误解/求而不得/身份落差/丧失）中指认 1 个主疼位；辅位可叠加、主位唯一 |
| 靶点 | 情绪任务的最小单元：爽/悬念/虐/甜/笑/泪/钩七类；总量与配额口径见 AT-33/14 |
| 微钩 / 小钩 / 中反转 | 三档钩子密度目标（AT-27/28/29）；埋设看目标、对标看实测带，两口径不互算 |
| 信息型钩子 | 带新信息（非纯情绪）的钩子；免费区加密校验的计量单位（AT-80） |
| 破壁词 | 打破第四面墙或典型 AI 腔的词汇；密度口径见 AT-39 |
| 黑名单 / 保护清单 | kill-ai 的禁用词表与禁误伤清单（真实细节与靶点句） |
| 采集卡 | 现实题材必收的真实细节输入；未填 = 声明"⚠️ 无真实素材注入"并列入阶段 6 重点复查 |
