# 阶段执行提示词与确认门摘要模板（prompts.md）

> 每个阶段一条可直接套用的执行提示词（[任务]/[输入]/[规则]/[输出]/[质量门] 五段式）+ 四道确认门的一页摘要模板。
> 提示词是执行的抓手，规则口径以各阶段文件与 ../references/shared/authority-table.md 为准；提示词与口径冲突时改提示词。

## 一、阶段执行提示词

### 阶段 1 · 选题

```
[任务]   以用户输入为锚 × 扫榜热点爆点交叉，产出 3 个候选选题，过双打分加严线与红线筛查，给出唯一推荐项
[输入]   用户想法/素材/一句话；赛道（可选）；对标作品（强引导）；真实细节采集卡（现实题材必收）
[规则]   ../references/stage1-topic/workflow.md 全量；扫榜覆盖七大平台（盐选/七猫/黑岩/点众/番茄小说短故事/豆瓣阅读/微信读书，
         新增三平台数据无来源标"待核"），热度四指标入表 + 征文活动信号单列（AT-75）；数据标来源，无来源标"待核"；
         双打分两套同时过线（三维 ≥25 且九维均分 ≥8）；红线 18 项命中 = 拒绝 + 必须给替代方向；
         结构指纹登记，与近 3 篇比对防同质化
[输出]   00-选题评估.md（六节）+ 08-结构指纹.md（计划指纹）
[质量门] 00+08 落盘；双打分同时过线；三关全过；红线/限流零命中；指纹无同型预警
```

### 阶段 2 · 梗概

```
[任务]   把选中选题压成梗概卡九字段，落成可验收的情绪任务清单
[输入]   00-选题评估.md 推荐项；采集卡；赛道情绪配方（../references/shared/genre-map.md）；题材正文卡（genre-cards/ 按 aliases 路由单卡）
[规则]   ../references/stage2-synopsis/workflow.md 全量；一句话梗概双版本（20 字极简 + 100 字扩展）；
         悬念三要素；70% 单线推进；双峰各 3 伏笔位 + 反转分级（A≥1、B+C 2-4）；
         反转铁律三条；情绪任务清单三项量化；意象闭环；弧光一句话；暂定标题三档合规；
         主疼位指认（AT-73：被辜负/被误解/求而不得/身份落差/丧失五型指认 1 个，初值借题材卡"常见情绪转化"）
[输出]   01-梗概.md
[质量门] 九字段齐；双版本齐；铁律三条全过；量化目标三项；标题合规；主疼位指认行齐
```

### 阶段 3 · 细纲

```
[任务]   先写上篇施工版（唯一事实源），再摘编下篇投前方案；单文件两篇
[输入]   01-梗概.md 全文；采集卡；../references/shared/fingerprint.md 六维枚举；题材正文卡（genre-cards/ 路由单卡）
[规则]   ../references/stage3-outline/workflow.md 全量；章制全文统一（纯数字独立成行）；付费点双卡 + 字位算术校验；
         卡点时刻落三型之一（撕裂/真相/抉择，AT-70）+ 卡点句自检三问；章题带情绪动词（前 3 章压黄金三章）；
         人设卡 + 配角动机句 + 命名四查；六张预埋表逐张填满（伏笔五字段可导出 CSV；
         名场面预埋表 ≥1 个，AT-69）；靶点配额按主疼位倾斜；黄金三章硬门；梗概承接核对；下篇四段摘编（人设/靶点表摘编，禁另写一套）
[输出]   02-细纲.md（单文件：上篇 + 下篇）
[质量门] 上篇门 + 下篇门均过 → 生成《细纲确认摘要》进确认门③
```

### 阶段 4 · 写作

```
[任务]   按细纲逐章成文：一次写一章、写完自检再进下一章；导语第 1 章前单独产，尾声末章后单独产
[输入]   02-细纲.md 上篇；time/道具台账；素材锚位；题材正文卡（genre-cards/ 路由单卡）
[规则]   ../references/stage4-draft/workflow.md 全量；动笔前三核对（节拍配额/钩位钩型/伏笔靶点）；
         单章自查表 9 条逐条对；三件套机检（check-length/metrics --fragment + check-ai）；
         导语过专项门（三要素：反常识场景/身份悬念/未完成动作，末句将破未破——AT-71）；
         第 1 章过开篇专项门（首句 3 秒入戏/前 30 字报类型+强冲突/300 字内凑齐冲突+主角+悬念）；
         末章过尾声专项门；全篇核验 7 项（含双锚句实测 + 中卡点 --midpoint 45%-55%、回收率 ≥80%、标称即实测）；
         长稿按批落盘（每批 2-3 章，批内仍逐章自检）
[输出]   03-正文.md（含导语/各章/尾声）；按批落盘
[质量门] 每章自查表 + 三件套；导语专项门 + 第 1 章/末章双专项门；全篇核验 7 项全过
```

### 阶段 5 · 润色

```
[任务]   工序 A 去 AI 味 + 语言润色（同一遍完成），工序 B 轻量标注；产出净稿与标注稿双版本
[输入]   03-正文.md 全篇；kill-ai.md 四层清单；style-rules.md 三档
[规则]   ../references/stage5-polish/workflow.md 全量；先润色后标注，顺序不可颠倒；润色改动边界
         （靶点句/金句位/伏笔双标句禁换核心意象词；情节人设问题不私改、登记待审）；
         check-ai exit 0 才算过；人味句豁免权在人工定级；标注七类**复合式**（【爽点+打脸】…，单类不计）+ 伏笔埋描一体（【伏笔·埋·Vx·描述】）+ 双版本一致性核验
[输出]   04-润色标注稿.md + 04-正文净稿.md
[质量门] check-ai exit 0；字数目标带；标注覆盖率 ≥90%（AT-14）；净稿三扫零命中；双版本逐字一致
```

### 阶段 6 · 初审与终审

```
[任务]   隔离审稿两轮制：初审 6a 结构化评审（只出问题清单不改稿）+ 终审 6b 放行
[输入]   审稿材料包六件（净稿/细纲六表/规则口径/机检数字报告/盲测对照源/上轮 Findings）；
         优先隔离 sub-agent 冷启动审稿（只给材料包、不给写作过程）
[规则]   ../references/stage6-review/workflow.md 全量；check-all 一键门 → MSS 机检 → 待人工复核清单 → check-artifacts 对账 →
         六维打分 → 逻辑八查 → Findings S1-S4 → 75 项拒稿门（勾选表见 `../references/stage6-review/quality-gate.md` 第三节）→ 四档结论双裁决取严；
         6b：跨章扫描 → 三测（盲测强制）→ 18 维 → 红队 → 工序留痕核（原平台口径/相似度两项条件项 已删）；
         修改按根因路由回上游 + 连带回改；S1/S2 全稿重进 6a，S3/S4 局部复审；每级回退 ≤2 轮
[输出]   05-初审报告.md（固定四节 + 机检数字报告附件）+ 05-终审报告.md（终审工序执行记录表 + 放行结论）
[质量门] 材料包六件齐；MSS 记录在案；初审均分 ≥7 无 S1/S2；终审 18 维达标 + 红队闭环 + 75 项全过（原平台口径/相似度两项条件项 已删）
```

## 三、方式①全自动 · 快照自检格式

连跑七阶段时，每道确认门降级为快照自检点——**不停留、可叫停**，每阶段落盘后输出一行摘要：

```
[阶段{N}·{名}] 产物 {文件名} 已落盘 | 门：{✅/❌ 关键指标} | 快照自检：{一行摘要} | 叫停回退：说"停"即可
```

自检纪律：快照不等于免检——产物照常落盘、质量门照常执行、编造防线照常生效；快照只省"等用户拍板"的停留，不省任何一道门。用户随时可对任一阶段发修改意见或叫停回退。

## 四、长稿断点提示词（新会话重进五步）

```
1. 读 SKILL.md 定位当前阶段（产物链缺号即断点在缺号处）；
2. 只加载当前阶段规则（卡一索引见 `../references/README.md` 第四节），禁全量加载 references；
3. 读项目目录上一阶段产物作输入（不读全部历史产物，不依赖对话记忆）；
4. 核对产物链完整（00-08 无跳号、与六表台账一致）；
5. 从中断处的质量门或确认门继续；产物链有缺口按根因路由回补，禁跳阶段硬续。
```
