# scripts/ — 执行面：9 个校验脚本 + 回归测试

> **本目录是什么**：零依赖 Python 校验脚本（只用标准库，python3 ≥3.8 可跑）。脚本只做**确定性检查**——可复算的事实判定，不判内容好坏（主观门走四档判定）。
> **卡二落地**：日常执行"该跑哪个脚本、传什么参"以本 README 为总表；各阶段 `../references/stageN-*/self-check.md` 只写"本阶段跑哪个"，按此回指防重复。卡一（该加载哪个规则）见 `../references/README.md` 第四节。

## 调用速查（10 项：9 个校验脚本 + 1 个回归测试）

| 脚本 | 何时跑 | 调用 | 退出码 | 降级人工口径 |
|---|---|---|---|---|
| check-length.py | 阶段 4 三件套/全篇核验；阶段 7 终稿 | `<正文.md> [--paywall "锚句" --first-twist "锚句"] [--intro "锚句"] [--midpoint "锚句"] [--target N] [--fragment]` | 0 达标 / 1 用法错 / 3 ❌ 级 | 按 docstring 字数口径人工数（中文字符+标点，不含空白与 MD 标记）；卡点字位用编辑器查找锚句字符位 |

| check-consistency.py | 改任何 SKILL/references/脚本后 | 无参（扫技能自身文件） | 0 全过 / 1 有失配 | 按 `../references/shared/authority-table.md` 逐条人工核对引用处 |
| check-all.py | 阶段 6 一键门；禁直出预交付门 | 无参 / `<项目目录>` / `<文件列表>` | 0 全过 / 1 子步骤失败 | 按本表各脚本降级口径依次人工执行 |
| tests/run-tests.py | 任何改脚本后必跑 | 无参 | 0 全过 / 1 回归失败 | 无降级——回归失败先修脚本再干活 |

**退出码语义（AT-56）**：0=全过；1=用法错误**或输入无效（空稿/空正文/文件不存在/参数错误）**；2=⚠️ 级待修/必改候选；3=❌ 级必修。预交付门聚合口径：任一脚本 2/3 = 修完再交（禁直出，见 `AGENTS.md`）。

**脚本降级三档**（环境/报错/损坏时）：① 按 docstring 口径人工执行同一标准；② 结果标"⚠️ 人工核验（脚本降级）"；③ 连续 2 个阶段靠降级通过 = 停下检查环境（宿主参数见 `../docs/install.md` §三）。**降级不降门。**

## 一键自检（改技能文件后必跑）

```bash
python3 scripts/check-consistency.py   # 跨文件口径一致性 + 死链检查（断言组数以脚本输出为准）
python3 tests/run-tests.py             # 金标准回归（正反对拍 + 九脚本覆盖）
python3 scripts/check-all.py           # 总门 = 探针 + 一致性 + 回归
```

任一退出码非 0 = 不得交付。改过脚本必跑 `tests/run-tests.py`；失败先修脚本再干活。

## 脚本边界（防误用）

- 脚本查**形式与结构**，不判"会不会爆"——效果边界见 `../SKILL.md` 铁律 5；
- check-mss 的标题/导语/梗概/金句必须显式传入（禁让脚本从正文猜）；
- 靶点句送检走整章 `check-ai.py`（脚本全文级，无单句送检模式，禁拆临时文件）；
- 空稿禁判绿：正文为空时三件套一律退 1 并点明"正文为空"。
